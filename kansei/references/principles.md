# 人が「良い」と感じる仕組み（知覚・心理の原則）

要素の「効果（なぜ良いか）」を説明するときの手がかりです。原則名を貼り付けるのではなく、**その作品のどこに、どう効いているか**を具体的に書くために使ってください。また講評で「なんかイマイチ」の原因を探すときの点検表にもなります。

## 見やすさ・分かりやすさ

| 原則 | 内容 | よくある失敗 |
|---|---|---|
| **視覚的階層** | 大きさ・太さ・色・位置の差で、見る順番が自然に決まる | 全部を同じくらい目立たせて、どこを見ればいいか分からない |
| **ジャンプ率** | 大きい要素と小さい要素のサイズ比。大きいと躍動的・広告的、小さいと落ち着き・知的 | 比が中途半端（1.3倍程度）で、差があるのかないのか曖昧 |
| **近接・整列・反復・対比** | 関係するものは近づけ、端を揃え、同じ扱いを繰り返し、違うものははっきり変える | 余白が均等で、まとまりが読めない |
| **ゲシュタルト（まとまり）** | 近いもの・似たもの・囲まれたものは、ひとまとまりに見える | 線や枠で区切りすぎて、うるさくなる |
| **処理の流暢性** | 理解しやすいものほど「好ましい」と感じる | 凝りすぎて読みにくい書体・配色 |
| **認知負荷** | 一度に処理できる量には限りがある。情報が少ないほど落ち着く | 要素を詰め込み、選択肢を増やしすぎる |

## 美しさ・心地よさ

| 原則 | 内容 |
|---|---|
| **統一と変化** | 揃っている中に、少しだけ違うものがあると心地よい。揃いすぎると退屈、変化しすぎると散漫 |
| **リズム** | 繰り返しと間。一定の周期と、その崩し方 |
| **余白（間）** | 何もない部分が、主役を際立たせ、品位・余裕を感じさせる。日本の美意識の「間」 |
| **比率** | 黄金比・白銀比・整数比など、関係が感じられる比率は安定して見える（ただし比率の名前より「比率が揃っていること」が重要） |
| **緊張と解放** | 期待させてから満たす。映像・音楽・文章・スクロール体験すべてに働く |
| **一貫した性格** | 全要素が同じ「人格」を持っていると世界観になる（丸い書体＋柔らかい色＋やさしい言葉） |
| **質感と本物らしさ** | 素材感・手の痕跡・不完全さが温かみや信頼感を生む。均一すぎると無機質 |

## 印象・感情

| 原則 | 内容 |
|---|---|
| **色の連想** | 彩度が低い＝落ち着き・高級、高い＝元気・若さ。暖色＝近い・親しみ、寒色＝遠い・冷静（文化差あり） |
| **形の連想** | 曲線＝柔らかい・親しみ、直線・鋭角＝力強い・知的・緊張 |
| **重さ** | 太い・暗い・下にあるものは重く安定、細い・明るい・上にあるものは軽い |
| **速さ** | 速い動き・短いカット＝興奮、ゆっくり＝落ち着き・高級感。イージングの柔らかさは丁寧さとして伝わる |
| **ピーク・エンド** | 体験の印象は、一番盛り上がった所と最後で決まりやすい |
| **ほどよい新しさ（MAYA）** | 「見慣れているが、少しだけ新しい」ものが最も好まれる。新しすぎると拒否され、見慣れすぎると退屈 |
| **フォン・レストルフ効果** | 一つだけ違うものは記憶に残る。アクセントは一つに絞ると効く |

## 「安っぽい」「素人っぽい」に見える主な原因

講評で原因を探すときの点検表です。

1. 余白が足りない、または均等すぎる
2. 文字サイズの種類が多い／ジャンプ率が曖昧
3. 色数が多い、彩度の高い色を広い面積に使っている
4. 純黒（#000）の文字と純白の組み合わせでコントラストが強すぎる
5. 影・グラデーション・角丸・枠線を多用している
6. 揃っていない（左端、ベースライン、画像のトーン、アイコンの線の太さ）
7. 情報を詰め込みすぎ、1画面のメッセージが多い
8. 動きが多い、速さやイージングがばらばら
9. どこかで見たテンプレートそのまま（平均的すぎて個性がない）
