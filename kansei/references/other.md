# 文章・コピー・その他の分野

## 文章・コピー・ネーミング

| 要素 | 観察すること |
|---|---|
| **長さとリズム** | 1文の文字数とそのばらつき、段落の長さ、体言止め・倒置の頻度、読点の打ち方 |
| **語彙** | 漢字・ひらがな・カタカナの比率、専門用語の量、擬音語、外来語 |
| **視点と距離** | 一人称・二人称、語尾（です・ます／だ・である／話し言葉）、読み手との距離感 |
| **具体と抽象** | 数字・固有名詞・五感の描写の量、抽象的な言葉との配分 |
| **構成** | 結論の位置、問いかけ、反復、対比、意外性の置き場所 |
| **余白** | 言わずに想像させている部分、省略 |
| **音** | 声に出したときの響き、語呂、母音・子音の印象（ネーミングでは特に重要） |

観察のしかた：文字数・文の長さは実際に数える。数値で書くと、制作時に「短くした」が具体的になる。

## その他（料理、空間、プロダクト、ファッション、UI の手触りなど）

AI が直接知覚できない分野では、**写真・図面・仕様・ユーザーの言葉**を材料にします。どの分野でも、次の汎用の観点で分解できます。

| 観点 | 例 |
|---|---|
| **素材・質感** | 素材の種類、表面の仕上げ、温度感、重さ |
| **形・比率** | 全体の比率、角の処理、厚み、部分と全体の関係 |
| **色・光** | 主調色、面積比、光の当て方 |
| **構成・配置** | 何をどこに置くか、余白、動線 |
| **時間・順序** | 体験する順番、最初と最後の印象、変化 |
| **五感** | 視・聴・触・味・嗅のうち何が主役で、何を抑えているか |
| **機能と感性の関係** | 使いやすさのための形が、美しさにもなっているか |
| **文脈** | 誰が、いつ、どこで、どんな気持ちで触れるか |

分野固有の観点が必要な場合は、その分野の基本的な評価軸を調べてから分解してください（例：料理なら味の五味・食感・温度・盛り付け・器、空間なら天井高・採光・素材・動線）。
