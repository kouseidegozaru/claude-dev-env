# 音楽・音声・効果音

AI は音を直接聴くことができません。**正直にそれを前提にして**、取り出せる情報とユーザーの言葉を組み合わせます。

## 情報の集め方

1. **ユーザーに聞く**（最も重要）：どこが好きか、聴いてどう感じるか、似ていると思う他の曲。時刻つき（「1:20 のところ」）だと分析しやすい
2. **楽曲の公開情報**：曲名・アーティストが分かれば、テンポ（BPM）、キー、ジャンル、編成、制作背景をWebで調べられる
3. **楽譜・コード譜・歌詞・MIDI** があれば、構成・和声・旋律を直接分析できる
4. **ファイルの解析**（ffmpeg がある場合）：
   - 長さ・形式：`ffprobe <file>`
   - 音量の推移（どこが盛り上がるか）：`ffmpeg -i <file> -af "astats=metadata=1:reset=44100,ametadata=print:key=lavfi.astats.Overall.RMS_level" -f null -`
   - 無音区間：`ffmpeg -i <file> -af silencedetect=n=-40dB:d=0.5 -f null -`
   - 波形やスペクトログラムを画像にして見る：`ffmpeg -i <file> -lavfi showspectrumpic=s=1280x480 spec.png`
5. 推測した内容（音色の質感、ミックスの印象など）は「推定」と明記し、ユーザーに確認する

## 要素一覧

| 要素 | 観察すること |
|---|---|
| **構成** | イントロ・Aメロ・サビなどの並びと長さ、サビまでの時間、繰り返しと変化 |
| **テンポ・リズム** | BPM、拍子、ノリ（ハネる／まっすぐ）、リズムの密度、休符 |
| **旋律** | 音域、跳躍の多さ、繰り返されるフレーズ（モチーフ）、山場の位置 |
| **和声** | キー（長調・短調）、よく使うコード進行、緊張と解決の位置 |
| **音色・編成** | 楽器の構成、生音か電子音か、声の質（息っぽさ・張り） |
| **ダイナミクス** | 音量の起伏、盛り上がりの作り方（楽器を足す／音域を上げる／止める） |
| **空間・ミックス** | 広がり、残響の量、低音の量、音の密度 |
| **歌詞・言葉** | 視点、語彙、具体と抽象の配分、音（母音）の響き |
| **間** | ブレイク、無音、余韻 |

## 見落としやすい点

- **引き算**：盛り上がりの直前に楽器を減らす、など「減らすことで効かせる」設計
- **緊張と解決**：期待させてから満たす（あるいは裏切る）タイミング
- 効果音・ジングルなら：長さ（ms）、立ち上がりの速さ、音程の上下が与える印象（上がる＝肯定、下がる＝否定など）
