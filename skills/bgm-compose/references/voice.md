# 声部書法・対旋律・内声（パッドを「面」から「声部」へ）

主旋律＋自動生成の伴奏・ベース・パッドという構成では、パッドが「和音の面」として
置かれがちで、内声の動きと対旋律が欠けやすい。このファイルは、声部を線として
扱うための規則を、生成と機械チェックに使える形でまとめたもの。
声部の呼び方: 主旋律=S、対旋律・内声上=A、内声下=T、ベース=B。
パッドを A と T の2声部に分解するのが全体の前提。
詳細と出典は `~/workspace/research_notes/bgm-compose-knowledge-20261119/voice-leading.md`。

## ボイスリーディング（声部の接続）

- **最小移動の原則**: コードが変わるとき、各声部は「共通音があれば同声部で保持」
  「無ければ最も近い構成音へ移動」。パッド／伴奏の配置はコードごとに独立に決めず、
  前コードからの移動コスト（Σ|各声部の移動半音数|）が最小になる候補を選ぶ。
  上声部の跳躍はベースに任せ、順次か3度以内を既定にする。
- **共通音の数で接続を決める**: 共通音2個（根音が3度・6度関係）=2声保持＋1声順次。
  共通音1個（4度・5度関係）=保持＋2声順次。共通音0個（2度関係）=上声部を
  ベースと反行させる。根音の移動量で分岐する決定表として実装できる。
- **傾向音の解決（機械チェック可）**: 外声の導音は主音へ上行必須・倍加禁止。
  和音の7度は下行順次で解決する。4度音は3度音へ下行。パッドに 7th の色音を
  置いた声部には、必ず下行解決を付ける（patterns.md の色音分担と直結）。
- **並行5度・8度の禁止（機械チェック可）**: 任意の2声部間で、完全5度→完全5度、
  完全8度→完全8度の連続を禁止する。反行で完全音程から別の完全音程へ移る場合も対象。
  全6声部ペアで検証し、違反時は転回形の変更で回避する。並行3度・6度は推奨。
- **運動の優先順位**: 反行＞斜行＞類行＞並行。特に S と B（外声同士）は反行を既定にし、
  ベースが順次進行する箇所では上声部を反行させる。
- **交差と間隔**: 声部の上下順序を常に保つ（A が S を超えない等）。隣接する上声部間の
  間隔は1オクターブ以内、T-B 間は1オクターブ超え可。声部ごとの音域を仕様書の
  パート定義に必須項目として持たせ、生成時にクランプ＋検証する。
- **倍加**: 4声で三和音を鳴らすとき、基本形=根音、第1転回形=ソプラノ音か5音、
  第2転回形=バス音を倍加する。導音は絶対に倍加しない。音を落とす優先順位は
  5音＞根音（ベースが担当）＞3音・7音（ガイドトーンは落とさない）。

## 対旋律

- **第一規則はリズムの補完**: 対旋律は、主旋律が休符・長音・息継ぎの箇所で動き、
  主旋律が活発な箇所では持続音か休符で退く。判定基準は「息継ぎ位置がずれているか」
  （同じ場所なら対旋律ではなくハモリ）。数値規則: **対旋律の発音の7割以上を、
  主旋律の音価が2拍以上の区間と休符区間に置く**。まず最大の隙間1か所に
  4〜5音の応答フレーズを置く形から始める。
- **音程規則**: 強拍での主旋律との同時音程は協和音程のみ。3度・6度を中心にし、
  完全音程（5度・8度）は全体の半分未満に抑え、類行・並行で完全音程に入らない。
  開始と終止だけ完全協和にする。不協和音程は経過的にのみ使い、直ちに順次解決する。
- **独立性**: 反行を基本とし、主旋律より5〜12半音下（または十分上）に置く。
  音量は主旋律より vel で 15〜25 低く。素材は主旋律のモチーフの断片・反行・
  リズム変形から作り、無関係な新素材を持ち込まない。単独で抜き出しても
  旋律として形になる輪郭を持たせる。
- **入退場**: 対旋律は曲の最初から置かず、主題の2回目の提示（A'）から加えるのが定石
  （繰り返しで加わると「展開した」感覚が得られる）。仕様書のセクション定義で
  入退場を指定する。

## 内声の動かし方

- **ガイドトーンライン**: 和音の3度と7度（ガイドトーン）が和声の性格を決める。
  これらを A・T に割り当て、「今の音から最も近い次のガイドトーン」へつなぐ
  ラインとして設計する。パッド生成を「和音の面」から「2本のガイドトーンライン
  ＋任意の色音」に再設計するのが、このファイルの中心的な提案。
- **経過音・刺繍音（後処理パス）**: 内声が3度以上跳ぶ箇所や、同じ和音が続いて
  内声が止まる箇所に、弱拍の経過音（半音経過音も可）と刺繍音を挿入して線を止めない。
  挿入後は並行5度・8度のチェックを再実行する（経過音が並行を作ることがある）。
- **掛留音（サスペンション）**: 前コードの構成音を持ち越して強拍で不協和にし、
  下行順次で解決する3段階の型（準備→掛留→解決）。型はベースとの音程で 4-3、
  7-6、9-8。解決先の音を解決の瞬間に他声部で先取りしない。置き場所は内声が最適。
  終止直前（V の前）への自動提案が現実的。
- **同音を打ち直さない**: 内声で同じ音を拍ごとに打ち直すと「面の点滅」になる。
  同一和音が続く場合はタイで持続を既定とし、変化が欲しい小節では再配置
  （構成音の声部間入替・オクターブ移動）で対応する。アルペジオは声部の
  「演奏法」であって配置替えではない、と捉える。

## ボイシングとレジスター

- **クローズ／オープン／ドロップ2**: クローズ=構成音を1オクターブ未満に密に積む
  （緻密・力強い）。オープン=1オクターブ超に開く（広がり・透明感）。低音域では
  クローズが濁るためオープンを選ぶ。ドロップ2は機械的な作り方: 4音のクローズ
  配置を作り、上から2番目の音だけを1オクターブ下げる。声部接続を保ったまま
  開いた響きが得られるため、パッド生成の変換関数として実装しやすい。
  仕様書の伴奏・パッドに `voicing: close|open|drop2` の指定を持たせる。
- **転回形の使い分け**: 基本形=開始・終止・セクション頭（強い確定感）。
  第1転回形=ベースラインを順次にしたい箇所、経過的な接続（軽く滑らか）。
  第2転回形=使用場面を限定する（カデンツ型 I6/4→V、ベースが順次で通過する
  経過型、ペダル型の3型のみ許可）。
- **短9度回避**: 声部間に短9度（半音＋1オクターブ=13半音）の関係を作らない
  （「正しい音の集まりなのに濁る」最大の原因）。長調和音の自然な11は3度と
  短9度を作るため避け、使うなら #11 にする。使えるテンションの目安:
  メジャー系=9, #11／マイナー系=9, 11／ドミナント系=ほぼ全部可。
  配置の原則は「下にガイドトーン、上に色」。
- **レジスター（音域帯）の配置**: 低い音ほど間隔を広く（最低2音の間隔は完全5度=
  7半音以上）、高い音ほど狭く（3度・6度）。上声部同士は1オクターブ以内に寄せ、
  ベースとの間だけ広くてよい。同じ音を同じオクターブで2パートが同時に鳴らす
  重複は避ける（厚みが欲しい場合はオクターブ違いで）。
- **主旋律の帯域を空ける**: 主旋律が使う音域帯を先に決め、伴奏とパッドの最高音は
  その下限より下に収める。伴奏が主旋律より上に出るのは、主旋律が休んでいる
  小節だけにする。パッドが主旋律帯に入る場合は、vel を下げるか音域を下げるかで
  「主旋律帯の住人でない」ことを明確にする。

## 実装への優先順位（調査者の所見）

1. パッドを2声部（A/T）に分解し、最小移動コストで接続する（ガイドトーンライン化）。
2. 検証ルールの追加: 並行5/8度、傾向音の解決、短9度、声部交差・音域はすべて
   機械チェック可能で、check_midi.py の拡張として入れられる。
3. ドロップ2変換は小さな実装で響きが変わる。
4. 対旋律パートの新設は、リズム補完の数値規則（発音の7割を主旋律の隙間に）が鍵。
5. 掛留音と経過音は後処理パスとして足すと、内声に表情が出る。

（優先順位1〜5の compose.py への組み込みは、改善計画のフェーズ3で扱う。
このファイルは当面、仕様書を書くときの設計規則として使う。）
