# 良いメロディの作り方（主旋律の設計手順）

主旋律を「音を並べる」作業として書くと、モチーフの無い、平坦で耳に残らない線になる。
このファイルは、作曲指導と実務家の解説を調査して（出典は末尾）、
仕様書に主旋律を書く前に設計として固定する手順と、書いた後に数えて点検する基準をまとめたもの。
手順0の主題選別（候補の大量生成＋目隠し選別）と併用できる。選別を通さない場合でも、
この手順で設計すれば最低限の型は担保される。

## 失敗のパターン（先に潰す）

1. **モチーフが無い** — 1音ずつ思いつきで繋ぐと、聴き手が何を覚えればいいか分からない。
2. **音域が平坦** — 同じ高さでうろうろするだけだと起伏が無く、跳躍が無さすぎても退屈になる。
3. **フレーズの終わりが弱い** — 終わり方が毎回ぼんやりしていると「曲」ではなく「音の列」に聞こえる。
4. **最高音の安売り** — 一番高い音を何度も鳴らすと、山場が消える。

## 設計手順

### 1. モチーフを先に作る（音高よりリズム）

- 核は **2〜4音＋特徴的なリズム**。メロディの identity は音高よりリズムにある。
- 例：付点四分＋八分＋二分（タ・タ・ターン）のような、口ずさめるリズム型を1つ決める。
- モチーフは主題セクションの中で **3回以上**、形を変えながら出す。
- 変形の既定は「**リズム型は固定し、音高列だけを変える**」（移高・反行・和声付け替え）。
  リズム型まで変えると別素材に聞こえる。リズム自体を変える場合はリズム変形として明示し、
  語彙は displacement（拍位置のずらし）・augmentation（音価2倍）・diminution（音価1/2）に限る。

### 1b. 署名の型カタログ（種作り: 型を選んでから音を埋める）

モチーフの「種」は自由に思いつくのではなく、型から作る。手順は固定する:

1. 場面と感情語に合う型を下のカタログから **1つだけ** 選ぶ。
2. 型の骨格（度数列＋リズム比）を仕様書のモチーフ欄に書き、署名スロットに収める。
3. 調の音階と小節の和声音に合わせて骨格を実音化する（音を埋める）。
4. 署名は主題に **1種類だけ**（既存の「署名音程は1種類だけ」の規則と同じ）。
   型を2つ混ぜると顔が2つになって散らかる。

| 型 | 骨格（度数列と音程） | リズムの骨格 | 向く性格 |
|---|---|---|---|
| 跳躍＋回収型 | 1→5→4→3→2（完全5度＝7半音 跳んで、順次で3音かけて戻る）。跳躍は6度〜オクターブまで可 | 跳躍音は長め（付点四分以上）、回収は八分〜四分で順次 | 明るく開けた主題。頂点への到達感 |
| 反復＋ずらし型 | 同じ3〜4音の型を2回。2回目は末尾1音だけ変えるか、開始を半拍ずらす | 型のリズムは2回とも同一（ずらしは開始位置だけ） | 覚えやすさ最優先。素朴で温かい主題 |
| 同音反復型 | 同じ音を3回刻んでから隣の音へ動く（例: 3・3・3→4→2） | タ・タ・タ・ターン（短・短・短・長） | リズム自体が顔になる。元気・素朴 |
| 問いかけ型（末尾を開く） | フレーズ末を 2度・5度・7度 のどれかで止め、次フレーズ頭で主音へ回収 | 末音は短めに切るか、逆に長く伸ばして「間」を作る | 続きを聴かせる主題。問いと答えの対と相性が良い |
| シーケンス登行型 | 短い型（2〜3音）を2度ずつ上げて2〜3回繰り返し、頂点へ届ける | 各回のリズムは逐語で同一 | 山へ向かう推進力。B（展開）の頭にも使える |
| 跳ね型 | 音程は順次中心にし、リズムの跳ねを署名にする（付点四分＋八分、シンコペーション） | 付点と裏拍の食いが型そのもの | 軽快・牧歌的。音高が平凡でも顔になる |
| 下行署名型 | 特徴的な下行列（例: 5→3→2→1、5→4→3→1）を型にする | 下行の各音に不等な音価（長・短・長など）を付ける | 落ち着いた・懐かしい主題。夕方や静かな場面 |

- 骨格の度数列は「運指レベルの設計図」として扱う: 実音化で度数を変える場合は、
  変えた理由（和声音への合わせ等）を仕様書に1行残す。
- どの型でも、輪郭の大域は定型（アーチ等）に寄せ、非典型なのは署名の1点だけに
  する（イヤーワームの配合と同じ原則）。

### 2. フレーズは「問いと答え」

- 単位は **4小節**。前半2小節が問い、後半2小節が答え。
- 問いは「開いて」終わる：フレーズ末の音は音階の **2・5・7度** など不安定な音に置き、
  和声も属側・準固有和音で止める。
- 答えは「閉じて」終わる：最後は **主音へ順次で着地**（2→1、または 7→1）し、長めの音で置く。
- 曲の最終フレーズだけは必ず閉じる。途中のフレーズは開いたままでよい（むしろ開ける）。

### 3. 構成は A A' B A''

- A（提示）：モチーフをそのまま出す。
- A'（反復＋微変化）：リズムは同じ、音高か終わり方だけ少し変える。
- B（展開）：リズムを崩す・音域を移す・シーケンス（同じ型を別の高さで繰り返す）で山へ向かう。
- A''（帰結）：モチーフに戻り、最後だけ閉じた終わり方にする。
- 目安は「**3回繰り返して4回目だけ変える**」。全部変えると覚えられず、全部同じだと飽きる。

### 4. 輪郭はアーチ型、最高音は1回だけ

- 全体の形は「上がって、頂点、降りて休む」のアーチ。
- **最高音（クライマックス・ノート）は曲全体で1回だけ**。置く場所は後半（全体の 2/3 付近）、
  強拍の頭に長い音で。頂点の前後はシーケンスで一段ずつ登って近づき、頂点からは順次で降りる。
- 音域は歌える範囲に収める：**1オクターブ＋数音（長10度程度）まで**。

### 5. 順次と跳躍は 7：3

- 隣の音へ進む「順次」を基本にし、離れた音への「跳躍」は全体の **約3割まで**。
- 跳躍は **1〜2小節に1回まで**。跳ぶ先と跳ぶ元はどちらもその小節の **和声音** にする。
- **跳躍の後始末は着地点で決める**（2026-11-19 の調査で精密化）: 着地点が音域の端
  （上位・下位25%）にある場合は反対方向へ順次で戻ることを必須とする。着地点が
  中央50%にある場合は同方向への継続も可（跳躍後の反転は「平均への回帰」の副産物で、
  中央着地では反転傾向自体が消えるため。全件反転を強制すると不自然なジグザグになる）。
  跳躍の連続はしない。

### 6. 和声との噛み合わせ

- 強拍（1・3拍目）の音はその小節の和声音を既定にする。非和声音は経過音として順次で挟み、
  次の和声音へ順次で解決する。
- フレーズの終わりには長めの音か休符を置いて「呼吸」を作る。音で埋め続けない。

## 書いた後の点検（数えて確認する）

仕様書の主旋律の表から数える。外れた項目は、印象への影響が大きい順に直す。

| 項目 | 基準 |
|---|---|
| 順次進行の割合 | 全音程移動の **65%以上** が順次（2度） |
| 跳躍の後始末 | **大きな跳躍（完全4度＝5半音以上）** で着地点が音域の端25%にあるものは、次が反対方向の順次になっていること（全件）。着地点が中央50%のものは方向自由。3度（3〜4半音）の小さな跳躍はこの限りでないが、跳躍の総数には数える |
| 最高音の回数 | 最高音の出現は **1回**（同音の連続再打は1回と数える） |
| 最高音の位置 | 全体の **55〜80%** の位置、強拍の頭 |
| モチーフの再現 | 主題セクション内でモチーフのリズム型が **3回以上** |
| フレーズ末 | 前半フレーズは開いた音（2・5・7度など）、最終フレーズは主音に順次で着地 |
| 音域 | 最高音−最低音が **長10度（16半音）以内** |
| 主題の戻り | check_midi.py の theme_check が PASS（再現部の逐語再現） |
| 署名音程 | 非典型な音程特徴（大きな跳躍1回、同音3連反復など）は主題に **1種類だけ**。輪郭自体は定型（上昇→下降、アーチ等）に寄せる |
| 意外性の回収 | 借用和音・偽終止・非和声音などの「はずれ」は **1〜2音以内に予測どおりの解決で回収** されていること。未回収の意外性イベントは **0件** |
| 新規音型の割合 | 4小節フレーズ内の初出音型は全体の **2〜4割**。展開部では提示部より下げる。0割と6割超は不合格 |
| フレーズ末の延長 | 末音の音価が境界の階層と比例していること（2小節境界=平均の1.5倍、4小節境界=2倍、セクション境界=2倍＋0.5〜1拍の休符）。小さい境界の末音が大きい境界より長い逆転は不合格 |
| 弱起の釣り合い | 弱起を使った場合、その長さと最終小節の短縮量が一致していること |

## 音楽心理学からの追加規則（調査 2026-11-19、第2次）

「覚えやすさ」と「意外性の効かせ方」を研究知見から規則化したもの。詳細と出典は
`~/workspace/research_notes/bgm-compose-knowledge-20261119/melody-psychology.md`。

- **イヤーワームの配合**: 大域の輪郭は定型に寄せ（覚えやすさ）、非典型な音程特徴は
  主題に1つだけ埋める（識別性）。2つ以上入れると「その曲の顔」ではなく散らかりになる。
  また頭に残る曲は平均より速いテンポを持つため、主題曲は場面BPM帯の上限寄りを
  既定にする（同じ場面の環境曲より +5〜10 BPM を出発点に）。
- **意外性は「予測が固まった場所」でだけ効く**: 快感は「低不確実性×高意外性」か
  「高不確実性×低意外性」で生まれる。借用和音・偽終止などの意外性イベントは、
  直前2小節以上が定番進行の位置にのみ置く。逆に転調など不確実性を上げた直後の
  1小節は、旋律を主音着地か和声音の順次に限定する（意外性の二重掛け禁止）。
- **はずれは必ず回収する（対照的価）**: 一瞬の落胆→即座の回収は、最初から的中する
  より快感が大きい。偽終止の次は2小節以内に本物の V–I を置く、非和声音は次の強拍で
  和声音へ順次解決する、という具合に「回収先をセットで書く」ことを仕様の規則にする。
- **到着の遅延**: クライマックス音と最終終止の直前に、直前音の延長・1拍の休符・
  同音反復で「ため」を1つ入れる（1曲に1〜2か所、遅延量は1拍〜1小節まで）。
  ループ境界では使わない（境界は予測どおりに回す）。
- **シンコペーションの予算**: 主題フレーズでは強拍の骨格（各小節1拍目の着地、
  フレーズ末の着地）を保ち、食いやタイによるシンコペーションは4小節に1〜2か所まで。
  指数0の小節ばかりでも、全小節が高シンコペーションでも不合格（快感は中程度で最大）。
- **反復はそれ自体が効く**: 機械的に挿入しただけの反復でも好感度が上がることが
  実証されている。新素材を足す前に「反復が足りていないから印象が薄い」可能性を
  先に点検する。主題セクション内でモチーフの逐語・準逐語の出現を最低2回確保し、
  A' の変形は1要素だけに限る。
- **フックの4条件**: (1) モチーフは冒頭15秒以内（ループ曲は1周目）に提示する。
  (2) 周囲と2軸以上（音域・リズム密度・和声の動き・編成の密度）で対比させる。
  対比は足すより引く（提示時は伴奏を薄くする）方が効くことが多い。
  (3) フックは1〜2小節に収める。(4) 再現時は1要素だけ変える。
