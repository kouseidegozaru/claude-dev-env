# 構成・形式・変奏技法

骨格選択（手順2）と仕様決定（手順1）で使う、形式と変奏と対比の知識。
patterns.md の「構成型」は既定の2型（曲型・ループ型）だけを置き、全体の
カタログはこのファイルが担う。
詳細と出典は `~/workspace/research_notes/bgm-compose-knowledge-20261119/form-variation.md`。

## 主題の内部構造

主題（8小節）の内部の作り方は2型から選ぶ。melody.md のフレーズ設計と併用する。

- **sentence（センテンス型、2＋2＋4）**: 提示部4小節（2小節の基本アイデア＋その反復、
  末尾の音だけ変えてよい）で主調を安定させ、継続部4小節は素材を1小節単位に
  断片化し、和声リズムを2倍に加速して、最後に1回だけ終止する。
  「安定した提示→不安定化して終止へ」という一方向の流れが文章の一体感を作る。
- **period（ピリオド型、4＋4）**: 前楽節は半終止で「開いて」終わり、後楽節は
  同じ冒頭から始めて完全終止で「閉じる」。対比は旋律ではなく終止の強弱と
  和声で付けるのが要点。後楽節の冒頭2小節は前楽節冒頭の再現にする。

## 骨格カタログ

- **binary（二部形式）**: A（8）｜B（8）。提示と対照だけの最小構成。短い曲や
  ループ素材向き。B は完全終止で主調に閉じる。
- **ternary（三部形式）**: A（8）｜B（8）｜A（8）。回帰が「帰ってきた」感覚を作る。
  patterns.md の曲型（イントロ→A→B→A'→アウトロ）はこの変種。
  長時間曲では各部自体が三部になる複合三部（大ループの中に小ループ）も使える。
- **aaba（32小節形式）**: A A B A。A を3回聞かせるため主題の定着が最も速い。
  主題を覚えさせたい曲（タイトル曲、町のテーマ）の既定候補。B は A と違う
  コード域（vi や IV 始まり）から始め、最後の A は末尾2小節だけ終止形に変えてよい。
- **rondo（ロンド）**: A B A C A のように主題 A が回帰し、性格の違う挿話を挟む。
  ゲームBGMの「同じ場所に戻ってくる」感覚と相性が良く、挿話だけ差し替えれば
  長時間化できる。A は毎回ほぼ同一（冒頭フレーズは逐語）、挿話は各8小節で
  A と最低2軸対比させる。A の回帰は3回まで、挿話は2種までを標準とする。
- **variations（主題と変奏）**: 主題提示のあと変奏を3〜5並べる。各変奏で
  「変える軸」を1つ宣言し、細分化の度合いを段階的に上げる。中盤にモード転換
  など大きな変化を1回置き、締めは原形の再現（reprise）か最大のクライマックス
  変奏（climax）のどちらかにする。

## 変奏技法のカタログ

共通原則: **主題の識別子（旋律の輪郭・和声進行・低音型・リズム型のどれか）を
最低1つ残し、変える軸は1変奏につき1つだけ宣言する**。識別子を全部変えると別曲になる。

- **装飾変奏**: 骨格音はそのままに、経過音・刺繍音・アルペジオで細分化する。
  `ornament_level`（0=原形、1=経過音追加、2=アルペジオ化、3=全面細分化）で指定し、
  変奏が進むほど段階を上げる。A' の標準変奏として既定値1〜2。強拍の骨格音は変えない。
- **リズム・拍子変奏**: 音価の拡大（2倍）・縮小（1/2）、シンコペーション、付点化、
  拍子の変更（4/4→6/8 等）。リズムは旋律の「顔」に強く依存するため効果が大きい。
  ループ型では拍子変更は継ぎ目の計算を壊すため曲型専用。
- **転調・モード変奏と再和声化**: 同主調への転換（長調⇔短調）は1曲1回まで。
  再和声化（旋律は保ちコードを差し替え）は、旋律の強拍音が新しいコードの
  構成音か経過音として説明できることを条件にする。
- **声部配置変奏**: 主題を低音部や内声部へ移し、上に新しい対旋律やテクスチュアを
  置く（`theme_voice: lead / bass / inner`）。ゲームBGMでは「メロディ消音」
  （聞き疲れ対策）の弱い版としても使える。
- **編成・テクスチュア変奏**: 楽器編成、音域（オクターブ移置）、重ね方、伴奏
  パターンを変える。実装コストが最も低く、ループ型の周回変化の主手段にもなる。
- **対位法・キャラクター変奏**: 主題の冒頭断片をカノンに流用する、主題を別の
  性格（行進曲風、子守歌風）に作り替える。変化量が最大級で、変奏列の山に置く。
  1曲に最大1回まで。

## セクション間の対比

- **最低2軸ルール**: 対比は音域・密度・和声の明暗と安定感・リズム・解決感
  （終止の強さ）の軸で作る。隣り合うセクションでは最低2軸を変える。
  1軸だけの変化は聞き流される。
- **変えすぎの禁止**: 変わる軸は2〜3まで。変わらない軸（調・テンポ・主題の
  有無）も最低1つ残す。全パラメータを変えると主題の同一性が消える。
  コードだけ変えるのは対比ではなく「ただのコード変更」（最も多い構造的失敗）。
- **対比は引き算で作る**: 際立たせたい側を盛るのではなく、前のセクションを
  絞る（要素数を最大セクションの3割程度まで落とす、音域を狭く低くする）方が
  効率的。セクションはまず4小節で書き、隣同士を続けて鳴らして対比を判定して
  から8小節に拡張する。
- **橋渡し**: B セクションが浮く場合は、B の冒頭に A のモチーフ断片を置く。

## 接続部（プレコーラス／ブリッジ）

- **pre（プレコーラス）**: 主題部の直前に毎回出る接続部。2〜4小節、両隣と違う
  コードでエネルギーを段階的に上げ、最終小節はドミナントで止めて主題部頭の
  主調へ接続する。出現回数は主題部と同数。「バースが既に主題部へ明確に
  向かっている曲では付けない」（付けすぎは推進力を殺ぐ）。
- **bridge（ブリッジ）**: 曲の約2/3の位置に**1回だけ**置く対照セクション
  （8小節標準）。新しいコード域・新しい旋律・違うリズム感で景色を変え、
  最後の主題回帰を新鮮にする。終わりは半終止で A の回帰を待つ形にする。
  現行の曲型の B はこのブリッジに相当し、**B の使い回し（2回出す）は禁止**。

## エネルギーの弧（energy_arc）

作曲前に、セクションごとの目標値を表にして仕様書の先頭に置く:
セクション名／小節数／density（パート数または音数密度の段階）／register
（旋律の平均音高の帯）／elements（使用パート一覧）。
弧を先に決めると、対比と遷移の判断が一貫する。全体の最高点は最後の
再現部（A'）に置き、A は「A' のための余白を残した版」として書く。
ブリッジは「低密度・高音域・静」のように密度を落として音域で対比する型も有効。
密度とダイナミクスの数値規則は patterns.md の「フィル・ブレイク・ダイナミクス」。

## イントロ／アウトロ／遷移

- **イントロの型**: `intro_type: riff / chords / ambient`。riff=曲を象徴する
  モチーフを先行提示、chords=本編のコード進行を楽器だけで1回通す（最も一般的）、
  ambient=質感と雰囲気だけを提示。いずれも本編の素材の流用が基本で、流用元
  セクションを必須指定にする。長さは場面BGMで2〜4小節、タイトル曲等では4〜8小節。
- **アウトロの型**: `outro_type: fade / cold / bookend / tag`。bookend はイントロと
  同一素材・同一編成に戻すことを規則化する。ループ型にはアウトロを持たない。
- **遷移の指定**: セクション境界ごとに `transition: none / fill / break / overlap / pull`
  を指定する。fill=最終小節で1パートが変奏して変化を予告、break=直前に全リズム
  要素を止める、overlap=前セクションの持続音を新セクションの1〜2小節目まで残す、
  pull=直前でパートを抜いて再入場の衝撃を稼ぐ。既定値は骨格ごとに決める
  （例: A→B は fill、B→A' は overlap）。フィルは最終小節のみ・担当パート1つまで。

## ループ設計の拡張

- **円環の和声接続**: 最終小節を V や経過和音で終え、継ぎ目を跨いで I へ解決させる
  （patterns.md のループ型）。継ぎ目で和声が解決すると、聴覚は再開ではなく
  継続として処理する。
- **長いループ＋内部の弧**: 標準は16〜32小節＋内部のエネルギーの弧（疎→密→疎）。
  ループ長を2倍にすると知覚される反復は約1/4になる、という実務知見がある。
  ジャンル別の目安: RPG の町・探索は1〜3分、環境系は2〜6分。
- **オスティナート＋ローテーション**: 短い反復型（ベースリフ、アルペジオ、
  リズム型）を固定層として置き、その上で他の要素を交代させる（旋律フレーズは
  1周おきに出る、パッドのボイシングが周回で入れ替わる等）。固定層が曲の
  アイデンティティを、交代要素が飽きにくさを担う。
- **周回ごとの変化（passes）**: 仕様書に周回ごとの変化表を持たせる
  （周回番号→有効レイヤー／変奏軸）。最低限の既定ローテーションとして
  「2周目は編成変奏、3周目は旋律を内声へ移置」。変化の極端形として、数周に
  1回メロディを消す、無音区間を挟む、パーツの提示順を組み替える、といった
  手法もある（GameDeveloper の繰り返し回避4改善策）。
- **短いループが成立する条件**: 主題の強さが高い場合のみ。旋律が弱い曲を
  短いループにするのが最悪の組み合わせで、その場合は長く＋内部変奏で補う。
  ループ長は主題選別のスコア等と連動して決める。
