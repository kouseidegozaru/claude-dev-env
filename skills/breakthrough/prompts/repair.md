# 修復担当への指示（作者に続きを頼めなかったときだけ使う）

まず `<RUN>/prompts/_common.md` と `<RUN>/prompts/_body.md` を読んでください。

- 課題: `<RUN>/charter.md`
- 案: 起動時に指定（本体 `<RUN>/pool/<ID>.md`、記録 `<ID>.notes.md`、試作物 `<RUN>/verify/proto/<ID>/`）
- 攻撃: 起動時に指定
- 対照解の修復のときは、本体は `<RUN>/control.md`、記録は `<RUN>/control.notes.md`（試作物は無い）

案の **核（「核」の節の仕組み）を変えずに**、攻撃で示された致命的でない弱点を直してください。
直すために確かめが要るなら、試作物を延長して確かめ、観測を引用してください。
核を変えないと直らない弱点は直さず、notes の「既知の弱点」に書いてください。

本体 `<RUN>/pool/<ID>.md` を上書きで更新し（`_body.md` の書式。経緯は書かない）、
`<ID>.notes.md` の末尾に「修復: 攻撃ファイル名 / 弱点 → 何を変えたか / 直さなかった弱点」を書き足してください。
受領証の ID は起動時に指定されたもの（`<ID>-fix`）を使い、元の受領証は書き換えないでください。
