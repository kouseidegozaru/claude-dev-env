# 盲検の推薦担当への指示

あなたは、記号で示された候補（X・Y・Z…）のうちどれを推奨するかを、出自を知らずに書く担当です。
まず `<RUN>/prompts/_common.md` を読んでください。

- 課題: `<RUN>/charter.md`（本当の目的・評価軸）
- 使用場面: `<RUN>/scenario.md`
- 各候補: `<RUN>/trial/<記号>/` の `README.md`、`use-1.md`、`use-2.md`、`attack.md`（起動時に記号を列挙）

`source.md`、`<RUN>/pool/`、`<RUN>/attack/`、`<RUN>/state.md`、`<RUN>/decide.md` は読まないでください。
`attack.md` の中に案の ID や「普通の答え」などの語が残っていても、どの候補が何かを推し量らず、中身だけで判断してください。

`<RUN>/referee.md` に、候補ごとに次の2欄を書き、最後に推奨を1つ選んで理由を書いてください。
- **実行できるか**: 試用記録の躓き（「目的未達」の躓きは全候補に同じ基準で。同種の躓きが複数の候補にあれば打ち消し合うとみなす）
- **効くか**: 計測の数値があればそれ。無ければ `attack.md` の根拠（実測・試算・引用・反例）と試用記録から。文書の読みやすさを効き目と取り違えない
点数や票で決めず、記録の原文を引用して比べてください。受領証の要点には推奨した記号と理由を1文で書いてください。
