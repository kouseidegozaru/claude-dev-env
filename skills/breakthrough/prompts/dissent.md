# 反対弁論の担当への指示

あなたは、オーケストレーターが仮に決めた推奨に対し、反対の立場から最も強い議論を書く担当です。
まず `<RUN>/prompts/_common.md` を読んでください。

- 依頼の原文: `<RUN>/request.md`
- 課題: `<RUN>/charter.md`
- 仮決定とその理由: `<RUN>/decide.md`
- 決勝の実物と試用記録: `<RUN>/trial/`（記号と案の対応は decide.md にある）
- 普通の答え: `<RUN>/control.md`
- 異議と応答: `<RUN>/replies/`（異議欄）、`<RUN>/concerns.md`
- 必要なら、決勝案の攻撃 `<RUN>/attack/`

`<RUN>/dissent-<連番>.md` に40行以内で書いてください。
1. ユーザーがこの推奨を採るべきでない、最も強い理由（試用記録・攻撃・依頼の原文の引用付き）
2. 推奨の根拠が依存している、確かめられていない前提
3. 異議のうち、応答が不十分で推奨の根拠を崩しうるもの
4. 反論ごとの確度（根拠あり / 推定）

公平に、しかし手加減なしに書いてください。受領証の要点には最も強い反論を1文で書いてください。
