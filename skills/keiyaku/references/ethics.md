# 倫理・法の点検（段5）

騙して作った契約は解約・返金・炎上・行政処分で戻ってくる。下に当たる施策は直すか外し、計画に入れない。**法的な判断は断定せず、弁護士など専門家への確認を勧める**（2026年時点の一般的な論点の整理で、法的助言ではない）。

## 1. ダークパターン（提案しない）

- 解約妨害: 解約を申込より難しくする（電話のみ、何画面も引き留め、ボタンを隠す）
- 偽の残り枠・緊急性: 実在しない「残り3名」「本日限り」、リセットされるカウントダウン
- 事前チェック: オプション・メルマガ同意・有料追加にあらかじめチェック
- 自動課金・合計金額・契約期間・自動更新を目立たない所や最終画面の後にしか出さない
- 断るボタンに恥をかかせる文言
- 根拠の無い実績表記: 実在しない口コミ・利用者数・合格率・No.1、算出方法を隠した数字

## 2. 日本の法規制の点検表

| 施策の種類 | 確かめる点 | 主な関係法令 |
|---|---|---|
| 広告・LP・チラシの表現 | 効果・実績（「〇日で変わる」「合格率」「No.1」）に合理的な根拠と算出方法の表示があるか（優良誤認）。価格・条件を実際より有利に見せていないか、二重価格、「無料」の条件（有利誤認）。広告であることの明示 | 景品表示法（優良誤認・有利誤認・ステマ告示） |
| キャンペーン・紹介特典 | 景品の上限額 | 景品表示法（景品規制） |
| ネット申込の最終確認画面 | 分量・総額・支払時期・申込期間・解約に関する事項が最終確認画面にあるか | 特定商取引法（通信販売） |
| 定期購入・サブスク・トライアル | 定期契約であること、2回目以降の価格、自動課金の時期、解約方法 | 特定商取引法、消費者契約法 |
| 訪問・電話の営業、教室・塾の長期契約 | 書面交付、クーリング・オフ、中途解約 | 特定商取引法（訪問販売・特定継続的役務） |
| 解約の受付・規約 | 解約方法の不当な制限、一方的に不利な条項 | 消費者契約法 |
| メール・メッセージ・通知 | 事前同意、送信者表示、配信停止の方法 | 特定電子メール法 |
| 顧客データ・行動計測 | 利用目的、第三者提供の同意、外部送信の公表 | 個人情報保護法、電気通信事業法 |
| 価格表示 | 消費者向けは税込総額 | 消費税法（総額表示） |
| 業種固有（金融・保険・医療・通信） | 業法の広告・勧誘規制 | 金融商品取引法、保険業法、薬機法 など |

法人向け（B2B）の契約では消費者向けの法令（消費者契約法・特定商取引法の一部）が当たらない場合があるが、景品表示法・不正競争防止法（品質誤認）・利用規約との整合・取引先の信頼の論点は残る。当たるかどうかは断定せず、専門家への確認を勧める。

日本以外の市場向けなら、その国の規制（EU 消費者保護・GDPR、米国の自動更新法など）を確かめるよう書く。

## 3. 書き方

上位3件それぞれに「該当なし」か「該当項目と対応（例: 最終確認画面に2回目以降の価格を出す）」を書き、計画表の「点検済み」欄に写す。既存の広告・チラシ・LP に当たる表現を見つけたら、施策と別に「表示の見直し」として計画に入れる。
