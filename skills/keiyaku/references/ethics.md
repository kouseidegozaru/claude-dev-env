# やってはいけないこと・法規制の点検

契約数は「顧客が納得して契約し、続けている数」。騙して作った契約は解約・返金・炎上・行政処分で戻ってくる。以下に当たる施策は提案しない。当たりうる点は施策表に明記し、**法的な判断は断定せず、弁護士など専門家への確認を勧める**（以下は 2026 年時点の一般的な論点の整理で、法的助言ではない）。

## 1. ダークパターン（提案しない）

- 解約手続きを申込より難しくする（電話のみ、何画面も引き留める、解約ボタンを隠す）
- 無料トライアル後の自動課金を目立たない場所にしか書かない
- 事前にチェック済みのオプション・メルマガ同意・有料追加
- 偽の希少性・緊急性（実在しない「残り3名」「本日限り」、リセットされるカウントダウン）
- 申込を断るボタンを恥をかかせる文言にする（「いいえ、損をしたいです」）
- 合計金額・契約期間・自動更新を最終画面まで出さない
- 実在しない口コミ・利用者数・実績・比較の捏造

## 2. 日本の法規制の点検表

| 施策の種類 | 確かめる点 | 主な関係法令 |
|---|---|---|
| 広告・LP の表現 | 「No.1」「最安」「業界初」などの根拠と出典表示。効果・性能の表示に合理的な根拠があるか。二重価格（通常価格の実績）。「無料」「0円」の条件の明示。ステルスマーケティング（広告であることの明示） | 景品表示法（優良誤認・有利誤認・ステマ告示） |
| キャンペーン・特典 | 景品の上限額（総付・懸賞）。紹介特典の設計 | 景品表示法（景品規制） |
| ネット申込の最終確認画面 | 分量・価格（総額）・支払時期・引渡時期・申込期間・解約に関する事項が最終確認画面に表示されているか。誤認させる表示が無いか | 特定商取引法（通信販売の申込段階の表示義務） |
| 定期購入・サブスク | 定期契約であること、2回目以降の価格、解約方法・条件の表示 | 特定商取引法、消費者契約法 |
| 訪問・電話による営業 | 書面交付、クーリング・オフの説明、再勧誘の禁止 | 特定商取引法（訪問販売・電話勧誘販売） |
| 解約の受付 | 解約方法を不当に制限していないか。消費者に一方的に不利な条項 | 消費者契約法 |
| メール・メッセージ配信 | 事前の同意（オプトイン）、送信者表示、配信停止の方法 | 特定電子メール法 |
| 顧客データの活用・行動計測 | 利用目的の明示、第三者提供の同意、外部送信（クッキー等）の公表・通知 | 個人情報保護法、電気通信事業法（外部送信規律） |
| 価格表示 | 消費者向けは税込の総額表示 | 消費税法（総額表示義務） |
| 業種固有（金融・保険・医療・通信など） | 業法上の広告・勧誘規制 | 金融商品取引法、保険業法、医薬品医療機器等法、電気通信事業法 など |

日本以外の市場向けなら、その国の規制（EU の消費者保護・GDPR、米国の自動更新法・FTC の規則など）を同様に確かめるよう明記する。

## 3. 点検の書き方

施策表の各施策に「点検」列を足し、`該当なし` か、当たった項目と対応（「最終確認画面に2回目以降の価格を表示する」など）を書く。対応できない施策は外す。
