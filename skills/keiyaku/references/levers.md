# 原因の確かめ方と段階別の施策

## 0. 原因の確かめ方（段3。数字は「どこで」しか言わない。「なぜ」は次で確かめ、無ければ集めること自体を施策にする）

| 情報源 | 分かること | 集め方 |
|---|---|---|
| 解約・退会理由（選択肢＋自由記述） | 価値が届かなかった点、価格、競合 | 解約フローに1問。自由記述の原文を読む |
| 失注理由（B2B） | 比較相手、決め手、稟議で止まった点 | CRM の失注欄、営業に直近10件を聞く |
| 問い合わせ・チャット | 申込前の不安（料金・解約・手間） | 直近3か月を分類して数える |
| 契約者・解約者への聞き取り（各5人） | きっかけ、比べた選択肢、迷った点 | 「最後に背中を押したのは何か」を聞く |
| 実物の操作 | 手数、入力項目、エラー、返信までの時間 | 申込完了・解約・問合せまで自分で操作して数える |
| 経路・理由の記録が無い | — | 紙1枚・30秒で書ける記録欄を作り、今日から付ける |

## 1. 流入

詰まりが流入にあるのは、各段の率が目安以上で母数だけが足りないときに限る。チャネル別の増分 CPA と、そのチャネル経由の継続率で配分する。合算の平均で判断しない。
- B2C: 意図の強い検索語の記事、紹介（双方に特典）、成果が出た直後の共有導線、提携。
- B2B: 業種・規模別の導入事例、比較表、ウェビナー、展示会の即日フォロー、代理店。
- 店舗・教室: 地図検索の情報整備、紹介、地域の掲示。チラシは配布地域・時期で部数を変えて経路を記録する。

## 2. 訪問 → 興味

- 最初の画面で「誰の何の問題を、どう解決し、いくらか」。顧客の言葉で書く。
- 広告の文言と着地先を揃える（広告で約束したものが着地先に実在するか）。
- 不安の先回り（料金・解約方法・縛り・手間）。証拠は実在するものだけ。

## 3. 興味 → 申込・体験

- 料金はプラン2〜3つ、税込総額。フォームは必須でない項目を後回しに。申込開始→完了が 60% 未満ならまずここ。
- トライアルの期間は価値体験までの日数に合わせる。B2B は見積もりの即時化、稟議資料、意思決定者の同席。
- 店舗・教室: 問い合わせへの返信時間、体験枠の曜日・時間帯、予約の手数。上限到達なら枠（時間帯・講師・担当）を増やす。

## 4. 申込 → 有効化

- 登録から最初の価値体験までの手数と日数を数えて減らす。最初に何をするかを1つ示す。
- 止まった手順ごとに連絡（メール・通知・電話）を出し分ける。トライアル終了前は終了日と課金を分かりやすく知らせる。

## 5. 継続（解約を減らす）

- 初月に落ちる → 約束と体験のずれ、オンボーディング。数か月後に落ちる → 利用頻度の低下を検知して連絡。
- 解約フロー: 理由を1問、代替案（一時停止・下位プラン）を1回だけ。手続きは簡単に保つ。
- 決済失敗による解約: 期限前の通知、再決済。年払い・利用実績の定期レポート。
- 単価（目標が売上のとき）: 上位プランは上限到達時に案内。値上げは告知期間と据え置き措置を設け `ethics.md` で点検。
