# 契約数の式・業態の型・詰まりの選び方

## 1. 式

```
有効契約数(翌月) = 有効契約数(今月) + 新規 − 有効契約数(今月) × 月次解約率
新規 = 流入 × 段1の率 × 段2の率 × …（容量のある段は min(前段 × 率, 上限)）
定常状態 = 月の新規 ÷ 月次解約率（届くまでの遅れは stock が出す）
```

- 率の分母を必ず書く（訪問比か問合せ比か）。広告費の判断は平均 CPA でなく**増分の CPA**（追加の費用 ÷ 追加の新規）で見る。新規が広告費に比例するとは置かない。

## 2. 業態別の型

段は「計測できる行動」で切る。計測できない段は推定と書き、計測を施策に入れる。

| 業態 | 段の例 | 典型の制約 |
|---|---|---|
| B2C セルフ申込（通販型サブスク・アプリ課金） | 広告表示 → LP 訪問 → 料金ページ → 申込開始 → 申込完了 → 初回利用 → 2か月目継続 | 通常なし |
| B2C 無料トライアル → 有料 | 訪問 → トライアル登録 → 有効化（初回の価値体験）→ 有料転換 → 継続 | 通常なし |
| B2C フリーミアム | 訪問 → 無料登録 → 定着（週次利用）→ 上限到達 → 有料化 → 継続 | 通常なし |
| B2B 営業型 | リード → 商談 → 提案 → 受注 → 定着・更新 | 商談枠と営業の人数 |
| 店舗・教室型（教室・塾・ジム・店頭） | 問合せ・予約 → 体験来店 → 入会 → 初月継続 | 体験枠・定員・講師 |
| 代理店型 | 代理店の接触 → 見込み → 申込 → 継続 | 代理店の稼働と手数料 |

- 複数チャネル・複数拠点は、チャネル・拠点ごとに funnel を回してから合算する。**合算だけでは率の差が隠れる**（悪いチャネルの増加が平均を下げ、良い段の改善を打ち消す）。
- 途中開業の拠点は開業月以降だけで率を出す。前段を通らない流入（紹介・兄弟・既存顧客）は note に書き、率から除くか別の段にする。
- 有効化の定義は、継続者がやっていて解約者がやっていない行動から決める。

## 3. 詰まりの選び方（段2）

1. `funnel <csv> --churn <月次解約率> --months <期限までの月数>` で、各段が target に届いたときの増分を**期限時点の有効契約数**で出す。
2. `stock --new-x K --churn-x K` で、新規増と解約減の期限時点の増分を出す。1と同じ単位で並べ、大きい方から施策を探す。
3. 最終段が契約後の段（継続など）のときは `--contract <契約の段>` を付け、増分を契約数に換算してから並べる。
4. 容量: 受付で待ち・断りがあれば、その段に `cap`（上限）と `wait`（待ち・断り）を入れる。上限到達の段は率を上げても増分0。`gain@枠` が大きければ「枠を増やす」が候補になる。
5. target は**自社の過去最良**を優先する（`target_src` に月を書く）。業界の目安を使うなら出典を書く。出典が無ければスクリプトが「仮の値」と出す。
6. 母数30未満（印 n<30）の段: 3〜6か月を合算して再実行する。合算しても30未満なら率の大小で順位を付けず、失注・離脱の理由の原文（商談メモ・問合せ文面）を読んで決め、「定性で決定」と書く。原文も無ければ「保留」とし、理由の記録開始を計画の1番目に置く。

## 4. データが無いときの仮置き（実データがあれば使わない。幅で置き「推定」と書く）

| 段 | 幅 | 段 | 幅 |
|---|---|---|---|
| LP 訪問 → 申込（低単価） | 1〜5% | 訪問 → トライアル登録 | 2〜10% |
| 申込開始 → 完了 | 40〜80% | トライアル → 有料（カード必須） | 30〜60% |
| B2B 問合せ → 商談 | 20〜50% | トライアル → 有料（カード不要） | 5〜20% |
| B2B 商談 → 受注 | 15〜35% | 月次解約率 B2C／中小 B2B | 3〜10%／1〜4% |

## 5. CSV の形式

```csv
stage,count,target,target_src,cap,wait,note
問合せ,120,,,,,3か月合算
体験来店,48,0.5,自社の過去最良 2025-11,48,15,平日夕方のみ
入会,30,0.7,,,,
```

- `count` は人数・件数。空欄・「不明」・率（75% など）はスクリプトが止める。0 にせず確かめるか推定値を入れる。出力: `rate` 前段比、`gain@target` target 到達時の増分、`gain@+10%` 相対 +10% の増分、`gain@枠` 待ち・断りを受けたときの増分。
