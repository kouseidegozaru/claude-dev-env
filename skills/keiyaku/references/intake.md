# 段0 受付

始める前に次の6項目を埋める。データ・依頼文・ファイルを見れば分かる項目は聞かない。

| 項目 | 確かめること | 欠けたとき |
|---|---|---|
| 目標の単位 | 契約数（新規）／純増／有効契約数（月末時点）／MRR・売上。定義（トライアル中を含むか、休会を含むか） | 有効契約数の月末値と仮定 |
| 期限と現在値 | 何年何月末までに、今いくつか | 依頼文の数字。無ければ「12か月後」と仮定 |
| 業態 | B2C サブスク／B2B 営業型／店舗・教室型／代理店型（`funnel.md` 2） | 申込の経路から判断して書く |
| 手元データ | 期間、各段の母数、欠損（空欄・「不明」・未集計の拠点）、表記ゆれ、重複行、合計行 | 欠損は 0 にしない。推定の幅と「推定」 |
| 待ち・断り | 体験枠・定員・講師・商談枠が満杯で待たせた・断った件数 | 「容量の制約なし」と仮定し、確かめ方を計画に入れる |
| 予算・人員 | 使える費用、担当者の名前・役割・使える時間 | 計画の担当欄を役割名で書く |

## 質問の仕方

- 最大3問。AskUserQuestion で選択式。判断を変える項目（目標の単位、容量、定義、「効いた？」と同じ時期の他の変化）から聞く。聞いていないことを答えとして書かない。
- 答えが無い・「分からない」なら、その項目を「仮定: 〜」と受付表に書いて進める。仮定は計画の冒頭にも並べる。

## 目標が売上・MRR のとき

```
月商 = 有効契約数 × ARPU（＋講習・オプションなど単発の売上）
```

- 有効契約数は `stock --months <期限までの月数> --arpu <ARPU>` で**期限時点の値**と期間の売上を出す。新規を増やす案と解約を減らす案を、期限時点の月商で比べる。
- 定常に届くまでの遅れ（stock の「90% が埋まるまで約 N か月」）を必ず書く。期限内に届かない改善は期限時点の値でしか効かない。
- 単価 × 継続月数（LTV = ARPU × 粗利率 ÷ 月次解約率）は、獲得単価（CPA）の上限を決めるときだけ使う。目標の見積もりには使わない。
- 年度の売上目標は、期首の在籍・卒業や満期の抜け（`--exit 月=件数`）・定員（`--cap`）・新拠点の通年化を分け、拠点ごとに stock を回して合計する。

## 解約の数え方

- 月次解約率 = 当月の解約 ÷ 月初の有効契約数。卒業・満期・受験終了など**予定された終了**は解約から分け、別に引く。
- 休会・一時停止は解約と分けて数え、どちらに入れたかを書く。
