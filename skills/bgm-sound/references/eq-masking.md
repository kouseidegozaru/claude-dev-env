# 周波数バランス・マスキング・EQ（eq-masking.md）

基準曲への周波数バランスの寄せ方、パート間マスキングの回避、こもり・耳障りの
検出と EQ 処方、場面別の目標帯。ラウドネスは references/loudness.md、
ステム処理の工程設計は SKILL.md 手順1b、症状からの入口は
references/failure-recipes.md（第2層）を参照。

## 測り方: 7帯域エネルギー比

スペクトルを 7 帯域に分け、各帯域のエネルギー比（%）を測る。旧来の低域比 1 本では
「低域は合っているのに 300 Hz がこもる」「3 kHz が刺さる」が両方素通りするため、
問題が起きる帯域と測定の帯域を一致させる。

| 帯域 | 役割の目安 | 初期許容（基準比との差） |
|---|---|---|
| 20–60 Hz | サブ低域 | ±7pt |
| 60–250 Hz | 低域（旧 低域比の中心） | ±15pt（従来踏襲） |
| 250–500 Hz | こもり帯 | ±5pt |
| 500–2k Hz | 中域（胴・土台） | ±7pt |
| 2–5k Hz | presence（輪郭・耳障り） | ±5pt |
| 5–8k Hz | 高域 | ±7pt |
| 8–16k Hz | 空気感 | ±7pt |

- 外れた帯域名を gate 出力に出す。
- 旧来の `band_low_pct`（20–250 Hz）は廃止せず、7 帯域の 20–250 集約値として
  派生で残す（差し戻し判定・golden 許容差・render の EQ ループが参照するため）。
- 帯域比と LTAS は**セクション単位でも測り**、全体と最もエネルギーの高い
  セクションの両方で判定する。セクション間の帯域比の差（例: B−A の 2–5k 比の
  増分）も記録する（全体平均は「A が暗く B が明るすぎる」を相殺して正常に
  見せてしまうため）。

## LTAS と tilt（処方の入力であり、ゲート条件ではない）

- 長期平均スペクトル（LTAS）を 1/3 オクターブ平滑で出し、基準との差分カーブ
  （dB）を処方の入力にする。±2 dB 以内の帯域は「一致」として処方対象から外す。
- スペクトル傾斜 tilt（dB/oct、60 Hz–12 kHz の回帰）を記録する。基準差 ±0.7 を
  初期の目安とする。
- **tilt と LTAS には深刻度（FAIL/WARN）を付けない。** 記録と処方の入力として
  使うだけに留める。

## 目標は「線」でなく「帯」で持つ

- 場面別ターゲットは、その場面でユーザーが高評価した曲のコーパス（場面ごとに
  最低 3 曲）から、帯域比の中央値 ± 四分位範囲で作る。
- **深刻度の段階**: 単一基準曲しかない間は全帯域 WARN 止まり。FAIL は場面
  コーパス（最低 3 曲）の帯ができた場面だけに適用し、**2 帯域以上が帯の外**で
  初めて FAIL とする（1 帯域の外れは WARN。編成差を欠陥化しない）。

## スペクトル比較前のラウドネス一致

- 計測用の比較では、両曲の統合ラウドネス差を 0.5 dB 以内に揃えてから
  帯域比・LTAS・tilt を比べる（音量差とスペクトル差を混同しないため）。
- ユーザーへの試聴提示用は ±0.1 LU を正とする（references/perceptual.md）。
  用途が違うため矛盾ではない。

## EQ 処方の順序（固定）

1. **不要帯域のカット**（役割別ハイパス。下表）
2. **相補カット**（競合側を 2〜3 dB まで、Q 1 前後）
3. **共振の狭いカット**（症状別処方参照）
4. **最後にだけ** presence の広いブースト（+1〜+3 dB）

- 1 パートあたりのカット合計は -6 dB を上限とする。それ以上必要なら EQ でなく
  編成の問題として作曲側へ差し戻す（references/failure-recipes.md 第6層）。
- ブーストはカットで不足したときだけ最後に使う。「主役を上げる前に、邪魔を引く」
  が原則。

### 役割別ハイパス／補正の初期値（ステム側）

| 対象 | HPF | 補正 |
|---|---|---|
| melody | 70 Hz | — |
| accomp | 100 Hz | 3 kHz に -2 dB の窪み（主旋律の presence 用） |
| pad | 120 Hz | 300–500 Hz に -3 dB |
| 彩り | 150 Hz | — |
| 低域を担わないパート一般 | 基音の下限の半音下〜役割別に 100–250 Hz | — |

## マッチ EQ の当て方

- LTAS 差分をそのまま当てない。平滑化して広い動きだけを残し、**適用量は差分の
  約 50%、1 帯域の上限 ±3.5 dB** で当てる（差分 100% は基準曲固有の音符や共振まで
  写し取る）。
- 当てた後は必ず**生描画から当て直して再計測**し、最大 2 回で止める。
- 反復ごとに全帯域の前後差を render_report に残し、「改善した帯域／±2pt 以上
  悪化した帯域」を明示する。2 回で帯内に入らなければ EQ では寄せ切れない問題
  （編成・マスキング設計）として作曲側へ差し戻す。

## 症状別処方

| 症状 | 帯域 | 処方 |
|---|---|---|
| こもり | 250–500 Hz | 最も混むステム群（パッド／ギター／ピアノ左手）へ Q 1〜1.5、-2〜-4 dB の広いカットを配分。単体パートやマスター一括だけで済ませない |
| 箱鳴り | 300–700 Hz | LTAS 差分に山があれば、その帯域を主担当とするパートへ Q 2〜4、-2〜-4 dB |
| 鼻音・ホンク | 800 Hz–1.5 kHz | 同上、狭めのカット |
| harshness（耳障り） | 2.5–6 kHz | 共振候補（1/12 オクターブ LTAS で近傍 ±1/3 オクターブ平均より +3 dB 以上突出した狭いピーク）を自動リスト化し、**耳確認（+6 dB 狭ブーストのスイープ）を通ったものだけ** Q 4〜8 で -2〜-5 dB 切る。大きな音のときだけ刺さる場合は動的カットへ |
| 暗い・抜けない | — | 先にこもり側の引き算をし、重心を再計測。それでも不足なら音源差し替え → 主旋律に 3 kHz 付近 +1〜+2 dB の広いブーストまで（failure-recipes.md 項目10） |

## マスキングの回避

- 静的処方の基本は相補 EQ（主役を上げる代わりに競合の同帯域を下げる）。
  定番の組: 主旋律 vs パッド／ギターは 2–5 kHz を競合側で -1〜-2 dB、
  主旋律 vs ギターの中域は 1–4 kHz で競合側 -2 dB、低域はベースと左手・
  パッド低音のどちらか一方に 60–120 Hz を譲り他方を -2〜-3 dB。
  いずれも広めの Q（1 前後）で始め、3 dB を超えたら編成側の問題として差し戻す。
- 衝突が一時的なら動的 EQ／サイドチェインで「その瞬間だけ」逃がす
  （対象帯域 -2〜-3 dB、ratio 3:1 目安、アタック 5–10 ms、リリース 60–120 ms）。
  ffmpeg で近似する場合はセクション単位の静的カットに落とし、常時カットとの
  違いを report に明記する。
- 仕様段階の周波数スロット（spec の任意項目 `freq_slots`: パートごとに主担当
  帯域を 1 つ決める）は設計をここに置く。音域設計そのものは作曲側の担当で、
  音色側は検出と警告までに留め、直しは仕様へ差し戻す。
- Bark 臨界帯域単位のマスキング検出は第 2 弾（ステム前提）。第 1 弾は
  帯域比＋LTAS＋相補 EQ の処方表までとする。

## 運用ルール（バイパス比較と小音量チェック）

- 分離の確認はモノでも行う（ステレオの広がりは衝突を隠す）。
- 納品前に、全カットをバイパスした状態とレベルマッチして比較し、
  **差が分からないカットは外す**（彫りすぎ防止）。
- EQ の決定は一定の中音量で行う。小音量チェックは「主旋律とベースの輪郭が
  残るか」の階層確認にだけ使い、そこで感じた低域・高域不足は処方にしない
  （等ラウドネス特性で小音量では低高域が先に痩せて聞こえるため。通常音量で
  こもった曲になる）。
