# ギター制作（guitar.md）

MIDI 作曲でエレキギターを「実在感のある音」で鳴らすための詳細。
素材の調達と検品、自作サンプルレンダラー、和音化、アンプ/エフェクター処理、
ジャンル別レシピ、トラブル対応をまとめる。
作曲そのもの（仕様書・MIDI 生成・マスタリング・納品ゲート）は SKILL.md の手順に従う。
音色プリセット本体は `scripts/guitar_fx.py`（SKILL.md 手順4e と対で使う）。

## 大原則: 信号の順序

- 実物のギターの音は「弦の生録音（DI）→ アンプで歪ませる → キャビネットで帯域が
  整う」の順で作られる。GM サウンドフォントの「歪みギター」プリセットは
  歪ませた後の音を1音サンプル化したもので、この順序が逆転しているため
  電子音感が強い。**エレキギターは必ず DI サンプル＋後段アンプ処理で作る。**
- 歪み処理（asoftclip 等）は必ずオーバーサンプリング（サンプルレートを上げて
  クリップし、ローパスして戻す）を挟んでから行う。44.1kHz のまま歪ませると
  エイリアシングでジャリジャリした音割れ様のノイズが乗る。倍率は歪みの硬さで
  変える: tanh かつ閾値 0.4 以上は 4 倍（176.4kHz）、閾値 0.34 以下・2段歪み・
  hard クリップは 8 倍（352.8kHz）。詳細は「歪み量の調整目安」の節。
- クリップ直後のローパスは音色作りであると同時にアンチエイリアス（折り返し
  除去）兼用である。**lp を外す・上げる改変は禁止**。明るさ調整は後段 EQ
  （presence 等）で行う。

## 素材: Karoryfer Black And Green Guitars（CC0）

- 実録 DI サンプル。Green = Gretsch Anniversary、Black = Hofner Club
  （いずれもホロウボディ）。twang サステイン、3ベロシティ層（p/mf/f）、
  ラウンドロビン付き、音域 E3（52）〜D7（98）。
- 配置: `~/workspace/soundfonts/bng-release/Samples/{green,black}/ord`
- **必ず公式 Release ZIP（Karoryfer_Black_And_Green_Guitars_1000.zip）から取る。**
  git クローン経由の WAV はリポジトリの .gitattributes（text=auto）でバイト単位に
  破損し、全点がノイズ化する（実際に踏み、ユーザーから「すごく音割れしています」と
  指摘された）。配布元の readme にも「Code ボタン経由は壊れる、Releases から取ること」
  と明記されている。
- ライセンス: CC0 1.0（商用可、台帳は references/instruments.md）。

### 素材の検品（使う前に必ず）

正常なギター音1音の目安: スペクトル重心 500〜1,500 Hz 程度、波形の大きな
不連続ジャンプ（隣接サンプル差 > 0.35）が 0 回、ピークはベロシティ層相応
（f で 0.7 前後、p で 0.1 前後）。破損品は重心 約11kHz・ジャンプ数万回になる。
ファイル名の音名と実音が合うかは FFT の最大ピークでも確認できる。

### 歪み段の検品（エイリアシング）

エイリアシングは低音ではほぼ発生せず、高音＋強歪みの組み合わせでのみ
顕在化するため、通常の試聴曲だけでは検出漏れする。固定手順として:
高音域の単音イベント（E6〜D7）を最強プリセット（lead_drive と fuzz）に通し、
スペクトルで「基本周波数の整数倍以外のピーク（折り返し成分）が出ていないか」と
スペクトル重心を目視確認する。8 倍化の効果確認にも同じ手順を使う。

## 自作レンダラー（scripts/render_guitar.py）

```
python3 scripts/render_guitar.py <ordフォルダ> <events.json> <out.wav> [rr_offset]
```

- イベント JSON は `scripts/dump_events.py <stem.mid> <out.json>` でステム MIDI から
  作る（開始秒・長さ秒・音高・ベロシティの列）。
- ベロシティ → 層の対応: 60 未満 p / 95 未満 mf / 以上 f。同じ音が続く場合は
  ラウンドロビンを巡回させる。音域外は最近傍サンプルを移調（線形補間）して代替。
- 音の末尾に 55ms のフェードを掛けてミュート感を出す。出力はピーク 0.89 に正規化。

### DI の基準レベル（キャリブレーション）

- プリセットの歪み梯子（boost dB／閾値）は、入力 DI の絶対レベルが前提である。
  render_guitar.py の**ピーク 0.89 正規化が「キャリブレーション済み基準」**で
  あり、この正規化値を変えたらプリセット梯子も無効になる。
- 別経路で作った DI（実録・他サンプルセット）を使う場合は、まず基準に合わせる:
  最も強いベロシティ層のピークが **−3〜−1 dBFS** に収まるよう正規化してから
  guitar_fx.py に入れる。
- サンプルセットごとの基準差は台帳に記録して前段で吸収する: 新規サンプル
  採用時に、同一 MIDI（E3 開放・ベロシティ 95・1 秒）を新旧両セットで描き、
  ピーク／RMS 差を台帳（references/instruments.md）に記録する。その差分を
  `volume=XdB` としてプリセット前段に挿入する（プリセット側でなく入力側の
  1 パラメータで吸収する）。
- 曲の memo に「DI 基準: render_guitar 0.89 / 外部（要正規化）」を 1 行残す。
- **ダブルトラックは本物らしく**: 同じイベントを rr_offset を変えて2回描き、
  別テイクとして左右に振る（片側だけ遅延＋コーラスで誤魔化すより実在感が出る）。
- 読み込み時に RIFF/WAVE ヘッダを検証し、壊れたファイルは除外する
  （ただし ZIP 版では破損ゼロを確認済み。検品は上の節で別途行う）。

## リードの和音化（harmonize）

単音のメロディラインは、その小節のコードのコードトーンを直下に最大2音足して
和音で弾くと厚みとギターらしさが大きく上がる（ユーザーの実聴でも単音より
和音版が選ばれる傾向を確認済み）。

- メロディ音が一番上に残るコードメロディ形式。追加音はメロディの 4〜13 半音下から
  コードトーンを選ぶ。追加音のベロシティは主音 −14、長さは主音 ×0.95。
- **強歪みで使う場合の追加音の優先順位**: 第1候補 = メロディの完全5度下／
  オクターブ下（完全音程は相互変調の差音が倍音列に乗る）、第2候補 = 3度下
  （ただしメロディが中音域以上のときのみ）。低音側に 3 度を密集させない
  （近い音程の密集配置ほど相互変調で濁る）。歪み側の受け方は下の
  lead_chord の節。
- リフ主体の曲（パンク系）ではリード全体に掛ける。バラード等ではサビだけ等、
  セクション限定も可。
- 雛形は `scripts/harmonize_template.py`。曲の spec.py（進行とコード定義）を
  読むので、曲フォルダに置いて使う。

## 音色プリセット（scripts/guitar_fx.py）

`python3 scripts/guitar_fx.py <preset> <in.wav> <out.wav> [--addon ...]`。
ミックス内では PRESETS の "pre" チェーンを `[in]...[out]` で挟む。
リバーブ系は生成 IR（`~/workspace/soundfonts/ir/` に spring/room/hall を自動生成）。

- 素直系: clean / twang / lofi
- 歪み系: crunch / overdrive / blues / distortion / lead_drive（2段）/ fuzz / metal
- モジュレーション系: chorus_clean / flanger_clean / phaser_crunch / trem_drive
- 空間系: surf / ambient / shoegaze
- 単体アドオン: chorus / flanger / phaser / tremolo / vibrato / delay_375 /
  delay_500 / slapback / presence / darken

### 歪み量の調整目安（実測の梯子）

- 軽い: 入力 +5dB、tanh 閾値 0.55（crunch）
- 標準: 入力 +5dB、閾値 0.34（distortion、リズム向け）
- 強い: 入力 +7dB、閾値 0.30（1段の上限目安）
- さらに強い: 2段化する（入力 +13dB → 閾値 0.30 → −3dB → 閾値 0.20）。
  1段を深くするより倍音が濃くなる（ペダル→アンプの重ね掛け相当）。
- ファズは hard クリップ＋閾値 0.25＋ローパス 3.8kHz で暗くする。
- ユーザーは歪み強めを好む傾向（「もう少し歪んで」「もっと歪ませて」と
  2段まで上げた経緯）。迷ったら強めから出して反応を見る。
- オーバーサンプリング倍率は梯子とセットで決める: tanh かつ閾値 0.4 以上
  （crunch／blues 級）= 4 倍のまま。tanh 閾値 0.34 以下、2段歪み、hard
  クリップ = 8 倍。clip() に倍率引数を持たせる（lead_drive のような clip() を
  使わない手書きチェーンも個別に 8 倍化の対象にする）。

### 前段 EQ（歪ませる前のハイパス）

- 歪みの後段のキャビ EQ とは別に、**前段で低域を切る**と「どの帯域がクリップ段を
  叩くか」が変わり、同じ閾値でも締まった歪みになる（低域が先に潰れる
  ブーミーな濁りを防ぐ。後段ハイパスでは得られない）。
- 歪み系プリセットに前段ハイパス（100〜150Hz、急峻）を追加した派生を用意する
  （例: distortion に `highpass=f=120` を追加した distortion_tight）。
  パームミュート主体のリズムで通常版と聴き比べ、合う方を曲の memo に残す。

### ノイズゲート（ハイゲイン用アドオン）

- 強歪みプリセット（lead_drive／metal／fuzz）はサンプル末尾の残響や無音部の
  ノイズを持ち上げる。ffmpeg の agate を使ったゲートアドオン（例: gate_tight）を
  歪み段の後・空間系の前に置く。
- 目安: threshold は無音部ノイズのピークより +3〜6dB 上、range は全閉でなく
  −20dB 程度に留めてサステインの尾を切らない。値の確定は無音部を含む
  実ステムで試すこと。

### 和音リード専用プリセット（lead_chord）

- 歪みは2音以上を同時に通すと和音外の和・差周波数（相互変調）を生成する。
  3度を含む通常の三和音は平均律の3度が純正比からずれるため差音が倍音列から
  外れ、濁りになる。EQ 後処理では直らず、発生源はクリップ段。
- harmonize で和音化したリードには、単音リード用より一段軽い専用プリセット
  lead_chord を使う。目安: 2段構成は維持しつつ**総ブーストを lead_drive の
  +13dB から +9〜10dB へ下げ**、**2段目の閾値を 0.20 → 0.28 に緩める**。
  前段ハイパス 150Hz を必須にする。追加音ベロシティ −14（和音化の節）も
  相互変調を抑える方向なので維持する。

### キャビ EQ の基本形

`highpass 78Hz / lowpass 5.4〜6.2kHz / 300Hz 付近を −2dB / 2.6〜3.2kHz を +1.5〜2dB`。
素材が明るい（ホロウボディの twang）場合はローパスを下げ、プレゼンスを控える。

### キャビ EQ の3バリエーション（マイク位置相当）

実キャビのマイク位置は EQ そのもの（中心＝最も明るく攻撃的、キャップ端＝
バランスの取れた標準、コーン外側／オフアクシス＝暗く丸い）。「明るすぎる／
フィズが気になる」は後段 EQ でなくキャビ側で直すのが第一手で、プリセットの
歪み量を変えずに明暗だけ動かせる。CAB を辞書化し、プリセット定義で選べる
ようにする。

| バリエーション | ローパス | 3.2kHz | その他 |
|---|---|---|---|
| cap | 7 kHz | +2.5 dB | 最も明るく攻撃的 |
| cap_edge | 現行 CAB そのまま | （現行 CAB） | 標準 |
| cone | 4.8 kHz | +0.5 dB | 250 Hz を +1 dB。暗く丸い |

素材が明るいホロウボディなので、リズム系の既定は cone 寄りから試す。
ダブルトラックでは左右で CAB を1段ずらす（後述）。

### 将来 IR を導入する場合の選定基準

現行は EQ でキャビを近似しているが、実 IR へ移る場合の選定基準を先に決めておく:

1. SM57 系（上中域の押し出し）とリボン／コンデンサ系（フラットで太い）の
   **ブレンド済み IR** を優先する（57 単体は明るく薄く、太いマイク単体は
   暗くなりがちで、ブレンドが実務解）。
2. マイク位置（cap／cap edge／cone）がファイル名で分かるライブラリ。
3. ジャンル適合: 4×12 V30 = ロック／メタル定番、1×12・2×12 グリーンバック／
   アルニコ = 低ゲイン系。

導入時は ffmpeg の afir で生成 IR リバーブと同じ仕組みに載せ替え可能。
まず cap_edge のブレンド IR 1本だけを distortion／lead_drive で現行 EQ
キャビと目隠し比較し、**勝った場合のみ**広げる。ライセンスは台帳に記録する。

## ステムミックスでのギター処理

- リズム: DI 2テイク → 各々にアンプ処理 → 左右に振る（L: 0.95/0.30、R: 0.30/0.95）。
  幅は**実テイク差（rr_offset 違い）＋音色差（左右で CAB を1段ずらす。例:
  L=cap_edge、R=cone）**で作る。遅延だけの擬似ステレオ（Haas）はモノラル再生で
  コムフィルタになるため使わない。
- リード標準チェーン（固定値）: **lead_drive（和音時は lead_chord）＋
  slapback アドオン＋ presence**、リバーブ送り −17dB。スラップは中央、
  110ms を −13dB で薄く足すと前に出る（リバーブより濁らず厚みと前方感が
  両立する）。曲側で毎回組み立て直さない。
- リバーブ送り（生成 IR、afir）: リード −17dB / リズム −20dB / ドラム −19dB /
  ベース −27dB が実証済みの出発点（punk／ロック系プリセット。場面曲の
  ジャンル別表は references/space.md）。
- 納品前の確認に**モノラル再生でのギター消失チェック**を1項目足す
  （モノラル再生があり得る再生環境で、ダブリングや幅処理が消えないか）。
- ベースは GeneralUser GS（FluidSynth 描画）＋軽い飽和＋コンプ。ドラムも同音源。
  acompressor の threshold は線形値（−20dB = 0.1、−16dB = 0.158）。

### 伴奏ギター用チェーン（bgm_backing）

ギターが主旋律でない場面曲では、伴奏ギターは中域で主旋律（ピアノ等）と正面
衝突する。「聞こえないから上げる」はマスキングを悪化させるだけで、正解は
削る＋下げる＋奥行きで引くこと。後処理プリセット bgm_backing（clean／crunch の
後段に付ける）として1セットに固定する:

1. 主旋律より −3〜−6dB 下げる。
2. ハイパス 100〜120Hz でベースに譲る。
3. 250〜500Hz の泥を −2〜−3dB 切る。
4. プレゼンス帯は主旋律と別の周波数を選ぶ（主旋律が 3kHz なら伴奏は上げない）。
5. 高域をローパスで丸める（darken アドオン、LP 4.2kHz を既定化）＝距離感。
6. コンプは「均すのでなく座らせる」: acompressor threshold=0.18、ratio 3、
   attack 15ms、release 80ms、ゲインリダクション 3〜5dB を上限
   （ピックのアタックを通すため attack は緩める。確認は試聴で「強い1発だけ
   飛び出さない」こと）。

奥行きは音量でなく**リバーブ送り量と高域の丸さ**で作る: 伴奏ギターの送りは
リードより多く（−13dB、IR は room、尾は短めで尾そのものが聞こえない程度）、
CAB は cone と併用可。主旋律交代（ギターが主役のセクション）では値を戻す。
twang（2.8kHz +3dB）は「前に出るギター」用であり伴奏には使わない。

## ナイロン／アコギの再現

- **既定チェーン: 「処理なし＋ボディ IR ブレンド＋リバーブ送り」のみ。
  コンプを掛けない。** 柔らかいアタックと短い減衰はナイロンの「優しさ」
  そのもので、コンプで均すと機械感が出る。ベロシティのばらつきは作曲側の
  ヒューマナイズで担保する。爪音的な明瞭さが欲しい場面だけ 3〜5kHz を
  +1.5dB する。
- ボディ IR ブレンド: アコギのボディは線形フィルタとして振る舞い、ピック
  アップ／DI 的な信号にボディのインパルス応答を畳み込むとマイクロフォンで
  録った音に近づく。無料のボディ IR データベースが存在する。afir で dry に
  wet **−12〜−18dB** 程度で薄く混ぜる（100% 置換でなくブレンドが破綻しにくい）。
  ピエゾ特有の硬さ対策として 200〜300Hz のこもりを −2dB、明瞭さが要る場合
  のみ 3〜5kHz を +1〜+2dB。ナイロンは基音が豊かで倍音が少ない音なので、
  高域を持ち上げてスチール弦化しないこと。**ボディ IR はライセンス確認の
  うえ台帳（instruments.md）に記録してから使う。**
- ピッキング位置の近似: 弦を弾く位置で倍音の欠け方が変わる（ブリッジ寄り＝
  明るく鋭い、中央寄り＝丸く太い）。静的な近似として場面別2プリセットを置く:
  nylon_normal（標準位置相当。第5倍音付近に −3〜−5dB の浅いノッチ）、
  nylon_soft（丸くしたい場面。第4倍音ノッチ＋ローパス 5kHz）。
  **音高でノッチが動かない近似である**ことは限界として明記する。
- FluidSynth のリバーブ尾で曲が数秒伸びる。末尾の RMS を見て内容の終わりを
  特定し、トリム＋フェードしてから loudnorm で −14 LUFS / TP −1 以下に寄せる
  （SKILL.md 手順6 のゲート準拠）。

## ジャンル別レシピ（実例つき）

### パンク（環境側の実例: ~/workspace/midi-bgm/punk/）
200 BPM、Em、44小節。リズム = drive8 のコード刻み＋ punk8 ベース、
リード = 和音化したフック。ギターは Black（リズム）/ Green（リード）の実録 DI。
歪みの変遷が「歪み量の調整目安」の実測元。

### 初期パンク/ピストルズ風（同: ~/workspace/midi-bgm/pistols/）
158 BPM、E 系 3 コード主体、64小節。コードリフ中心、合唱型サビ、
ベースは root_5_8 でコード間を動く。リズムの歪みは閾値 0.34 より重め、
リードは 2 段歪み。ブレイクはダブルストップ風リック（和音化が効く）。

### レゲエパンク/London Calling 風（同: ~/workspace/midi-bgm/clash/）
136 BPM、Em、72小節。バースは裏拍スタブ（リード側で短い和音スタブ）、
ベースが主役: compose.py の `drive8mel`（8分刻み＋オクターブ/5度差し込み＋
次ルートへの全音アプローチ）。サビはメジャー側へ持ち上げる。
※ 本家曲のメロディ/ベースラインの複写はせず、質感のみを借りて新規作曲する。

## トラブル対応

- **「音割れしている」→ まず素材破損を疑う。** 完成ミックスの数値が正常でも
  素材が壊れていれば全編ノイズになる。検品は「素材の検品」節の数値で切り分ける
  （DI ステム単体の重心が 9kHz 超なら素材側が原因）。
- 歪みでジャリつく → オーバーサンプリングを挟んだか確認する。
- 音が痩せる/明るすぎる → 素材がホロウボディ由来の個性。キャビ EQ のローパスと
  250Hz 持ち上げで寄せる。それでも重さが要る場合はハムバッカー系 DI サンプルの
  追加採用を検討（候補: Standard Guitar、ただしライセンス条項の確認が前提。
  references/instruments.md の台帳に記録してから使う）。
- 環境リセット後は fluidsynth と音源の有無を先に確認する（SKILL.md の前提節）。

## 既知の限界

- 素材はホロウボディ2種のみ。太いハムバッカーの壁のような音は素材の個性として
  届かない範囲がある（EQ と歪みで寄せるのが現状の最適）。
- ワウはこの道具立て（ffmpeg）に無い。フェイザーで代替するか、必要になったら
  Python の時変バンドパスで実装する。
- ナイロンギターは採用済みの複数層セットがまだ無い（当面 GM のまま）。
  候補（CC0・3層、未採用・要 SFZ 化と個別ライセンス確認）は
  references/samples.md の「ナイロンギター候補」の節に分離表記してある。
