# 空間系（リバーブ／ディレイ）（space.md）

主空間は 1 つ、全ステム共有のセンドリターンで作る。種別・減衰・プリディレイ・
送り量の決め方、リターン EQ、生成 IR の仕様、afir の正規形、ディレイの扱い。
ギター専用の空間系は references/guitar.md、ステム工程全体は SKILL.md 手順1b、
リバーブ過多の症状からは references/failure-recipes.md（第3層）。

## 大原則

- リバーブはステムごとのインサートでなく、100% wet のリターンを 1 本立て、
  全ステムが送り量だけ変えて**同じ空間を共有**する。空間は 1 曲に 1 つ（主空間）。
  別々の空間を重ねると「同じ場所で鳴っていない」バラバラ感が出る。
- **FluidSynth 内蔵リバーブと afir センドの二重掛けを禁止する。** 使うのは
  どちらか一方。ステムミックス経路では FluidSynth 側は素の描画とし、主空間は
  afir 側で作る。内蔵リバーブは一括描画の下書きレンダーだけに使う。
- **使用経路・IR 種別・RT60・プリディレイ・送り量表を render_report に必ず
  記録する。記録が無い成果物は未完成として扱う**（SKILL.md の前提節と対）。
- ベースと低域の打楽器は主空間へ送らない（例外でも -28 dB 以下＋リターン
  ハイパス必須）。低域比が基準を上振れしたら、EQ 補正の前にまず「低域を
  送っていないか」を疑う。

## リバーブ種別の選択

種別を「空間の性格」として先に 1 つ決める。種別が決まると減衰とプリディレイの
出発点が決まる。

| 種別 | 性格 | 既定の場面 |
|---|---|---|
| room | 小〜中・自然 | 室内・小空間などの日常場面 |
| plate | 明るく密・部屋感が薄い | 主題のピアノを前に出したい曲 |
| hall | 大・広がり | 夜・雪・広い場面 |
| chamber | 中・温かく複雑 | 夕方・懐かしさ |
| spring | バネ・揺れる個性 | ギター中心の曲だけ（guitar.md 側） |
| shimmer | ピッチシフト付きの夢幻 | 原則使わない。場面指定があるときだけ（「優しく明るい・素朴」の物差しと衝突しやすい） |

## 減衰時間（RT60）はテンポ同期の総量で決める

- 減衰は絶対値でなく、**プリディレイ＋減衰 ＝ 1/2 小節**（夜の疎な曲だけ
  1 小節）に丸め、減衰 ＝ 総量 − プリディレイ で逆算する。上限は 3.0 s で切る。
  尾が拍の区切りで消えると次のフレーズと衝突せず、空間がリズムの一部になる。
- 場面×密度の基本帯（出発点）: 朝（BPM 76–84）room/plate 1.2〜1.8 s、
  昼（84–92）room 1.0〜1.5 s、夕（72–80）chamber/plate 1.5〜2.2 s、
  夜（60–70）hall 2.0〜3.0 s（送りは最小）。
  密な曲（16 分音符のアルペジオ等が続く）は帯の下限側かつ上限 1.5 s、
  疎な曲は上限側。パッド・弦の持続音は素材自体が尾を持つので帯より
  -0.3〜0.5 s 短くする。
- 天気バリアントは種別を変えない: 雨 ＝ 同時間帯比で送り +3 dB・減衰 +0.3 s、
  雪 ＝ 減衰を同時間帯比 -0.4 s しダンピングを強める。
- ループ曲では RT60 はループ長の 1/8 以下を目安にする（references/loop-fatigue.md）。

## プリディレイと前後配置

- プリディレイは音価で決める。主旋律の既定は **128 分音符相当**
  （60000/BPM/32、BPM 62〜92 で 30〜20 ms）。空間を広く見せたいときや疎な
  夜曲では 64 分音符相当（/16）。パッドは 0 ms（持続音はアタック保護が不要で、
  遅らせると和音の変わり目が滲む）。
- 前後配置は 3 段で固定する:

| 位置 | 対象 | プリディレイ | 送りの相対 |
|---|---|---|---|
| 前面 | 主旋律 | 128 分相当 | 小さめ |
| 中面 | 伴奏ギター・ハープ等 | 10〜15 ms | 中 |
| 後面 | パッド・弦 | 0 ms | 大きめ |

- プリディレイをステムごとに変えるには、頭無音の長さ違いの IR を 2〜3 種
  用意して送り先を分ける。

## 送り量（ジャンル別プリセット）

数値はリターン合流時点でのドライ対比（wet レベル）。

### cozy 場面曲（既定）

| パート | 送り量 |
|---|---|
| 主旋律ピアノ | -18〜-22 dB |
| カリンバ／ハープ等の彩り | -16〜-20 dB |
| 伴奏ギター | -20〜-24 dB |
| パッド／弦セクション | -14〜-18 dB |
| 打楽器 | 短い room のみ -19〜-23 dB |
| ベース | 送らない（例外でも -28 dB 以下） |

### punk／ロック系（既存実績値）

| パート | 送り量 |
|---|---|
| melody（リード） | -17 dB |
| drums | -19 dB |
| accomp（リズム） | -20 dB |
| bass | -27 dB（cozy の上限 -28 dB に対するジャンル例外として明記する） |

### 最終調整手順（ジャンル共通の正）

1. リターンをミュートしてドライのみでバランスを取る。
2. 主旋律の送りを -30 dB から上げ、空間が「聞こえる」でなく「止めると
   物足りない」点で止める。
3. 他パートを表の相対関係で置く。
4. 全体を ±3 dB だけ動かして場面の広さに合わせる。

ソロで尾だけがはっきり聞こえる量は過剰の目安。

## リターン EQ（既定は穏当式）

リターンの前段（送りの合流後、afir の前）に EQ を入れる。

| 方式 | ハイパス | ローパス | 使う条件 |
|---|---|---|---|
| 穏当式（既定） | 200〜300 Hz | 6〜8 kHz | 通常の場面曲 |
| Abbey Road 式 | 600 Hz | 6〜10 kHz | 編成が密な曲・打楽器入り、およびリバーブ過多の救済（failure-recipes.md 項目15）のときだけ |

- 夜・雪の場面はローパスを 4〜5 kHz まで下げて暗くする（ダンピングと連動）。
- 前段で切るのが原則（入力に無い帯域は尾にも出ない）。主旋律の聞こえが
  変わらないこと、ベースの濁りが減ることを A/B で確認する。

## ダンピング（尾の暗さ）

尾の高域が時間とともに落ちる度合いを、IR 生成時のローパス周波数で決める。

| 場面 | ローパス |
|---|---|
| 昼・朝 | 7 kHz |
| 夕 | 5.2 kHz |
| 夜 | 4〜5 kHz |
| 雪 | 4 kHz |
| plate 的に明るくしたい主題曲 | 9 kHz |

実空間では高域ほど先に吸収されるため、暗くなる尾は自然で遠く、明るいままの尾は
金属的で安っぽく聞こえる。空間側で無理に明るくしない（明るさは進行と旋律で作る）。

## 生成 IR の仕様（作り替え済みの前提で書く）

- 減衰包絡は「RT60 でちょうど -60 dB になる指数関数」`exp(-6.9078 * t / RT60)`
  をノイズに掛ける（線形に近いフェードは使わない）。
- 左右は別シードのノイズで分離する（左右同一だとモノラル的な狭い尾になる）。
- IR は単位エネルギーに正規化する（IR を差し替えても wet 量の目安が再現する）。
- プリディレイは IR の先頭に無音として焼き込む。
- 初期反射（ER）は疎なタップ（43／61／87／97 ms 付近に振幅 0.5／0.35／0.25／0.18
  程度の短いインパルス列）を埋め込んで近似する。**生成 IR は本来 ER を持たず、
  「霧はあるが部屋が無い」音になりやすいことが弱点**である旨をここに明記する。
- ファイル名に RT60 とローパス値を含める（例: `hall_rt2.4_lp4500.wav`）。
  生成物は `~/workspace/soundfonts/ir/` に置き、生成スクリプトで再生成可能にする
  （手置きファイルにしない）。

### IR 種別（6 種、場面表と 1 対 1）

| 種別 | パラメータ |
|---|---|
| ambience | RT60 0.45 s・ER タップ強め・尾弱め（ドライ感だけを消す） |
| room | RT60 1.4 s（従来） |
| plate | RT60 1.9 s・ローパス 9 kHz・主旋律用にプリディレイ 20〜30 ms を焼き込んだ版も用意 |
| chamber | RT60 1.8〜2.4 s・ローパス 6 kHz |
| hall | RT60 2.6 s（従来） |
| spring | RT60 0.9 s（従来、ギター系） |

種別差は RT60／ローパス／プリディレイ頭無音／ER タップ有無だけで作る。

## 実 IR の採用条件

- 音の良さより先にライセンスを確認し、台帳（instruments.md）にアセット単位で
  出所・ライセンス・商用可否を記録してから採用する。
- 優先順位: (1) 再配布可が明文のもの、(2) 個別ファイルごとの CC 表示を確認
  できたもの、(3) EchoThief／Samplicity 系は「手元での生成に使うだけ・
  ファイルは同梱しない」条件でのみ検討し、判断を台帳に残す。

## afir の正規形

- `afir` の `dry` は入力ゲイン、`wet` は畳み込み出力のゲインであり、
  一般的な dry/wet ミックス比ではない。
- 正規形を固定する: 送り分岐だけを `[send][ir]afir=dry=0:wet=1:irnorm=1` に入れ
  → `volume=<リターンレベル dB>` → リターンバスへ合流。**ドライは afir の外で足す**
  （afir だけで完結させて二重にドライを混ぜない）。
- 尾の長さは生成段階の RT60 で決め、`length=1` のまま使う（`length` での
  切り詰めは切れ方が不自然）。

## リターンのダッキング

- リターンにドライの主旋律をキーにしたコンプレッサーを入れ、主旋律が鳴って
  いる間だけ尾を **2〜4 dB** 下げ、フレーズの切れ目で尾が戻るようにする
  （下げ幅 6 dB 超はポンピングとして聞こえるので上限）。
- ffmpeg の `sidechaincompress` を使う。開始値: ratio 4、attack 5 ms、
  release は「プリディレイ＋減衰の総量」の 1/4 程度。

## ディレイ（空間ではなく拍同期の反復）

- ディレイはリバーブの代わりにしない。使い分け:
  スラップバック（90〜120 ms・反復 1 回・テンポ非同期）＝音を太く前に、
  付点 8 分（45000/BPM ms）＝跳ねる奥行き、8 分（30000/BPM ms）＝締まった
  リズムの厚み、4 分（60000/BPM ms）＝疎な夜曲の広い反響。
- cozy の既定は付点 8 分を主旋律かギターの**どちらか 1 パートだけ**に薄く使う。
  非同期の長いディレイはリズムと衝突して「忙しい」印象を作るので常用しない。
- ffmpeg の `aecho` はフィードバック型でなく多タップ型。反復は遅延 D に対し
  等比タップ列で作る（例: `aecho=0.8:0.85:D|2D|3D|4D:0.35|0.12|0.04|0.015`）。
  反復ごとに暗くするには出力へローパスを追加する。
- 戻りにはハイパス 200 Hz＋ローパス 5〜8 kHz を入れ、wet はドライ比
  -12〜-16 dB を上限とする。フレーズの切れ目でのみ反復が聞こえる量が上限。
- ピンポンは左右タップずらしの簡易構成で代替する。**未検証の近似**として扱い、
  導入時は必ず試し鳴らしで左右の跳ね方を確認する。

## ループ尾

ループ曲の尾は切り捨てでなく頭へ回す（定常状態レンダリング: 3 周描いて
2 周目を切り出す）。詳細は references/loop-fatigue.md。
