# 点検表（学習・制作・講評で共通）

学習・制作・講評の仕上げに使う1枚です。使い方は2つあります。

- **学習（手順5）**: 参考作品そのものに「C. AI の典型」を掛け、当たった項目を**免除リスト**（参考の顔）としてプロファイルに書く。
- **講評（手順4）**: 対象（制作物）に全項目を掛ける。各項目は Yes/No ではなく、**「参考の○○と同じ／違う」の比較**で書く。参考が無い講評では「AI の既定値と同じ／違う」で書く。

## 書き方

| 項目 | 参考では | 対象では | 比較 | 判定 |
|---|---|---|---|---|
| 角丸＋影のカード | 使っていない（カード 0） | 料金を角丸 8px の箱で囲んだ | 参考と違う | 修正 |
| 字間の広い英大文字ラベル | 各セクションの左上だけ、10px（免除リスト） | 同じ位置・同じ大きさ | 参考と同じ | 可（免除） |
| 字間の広い英大文字ラベル | 同上 | ヒーローの上に 18px の "WELCOME" | 参考に無い場所へ広げた | 修正 |

判定は「可」「修正」「可（免除）」「ユーザーに確認」のどれか。免除は**参考と同じ使い方**のときだけ。免除の「可」が3つ以上そろったら、骨組みの写しになっていないかを並べた1枚で確かめる（`references/learn.md` 手順5）。根拠がプロファイルの引用（決定表の (a)）かユーザーの言葉の引用（(b)）で示せない「可」は書かない。

---

## A. 書いたもの（プロファイル・決定表・講評の文章）

- [ ] 「モダン」「洗練」「シンプル」「スタイリッシュ」などの言葉を、数値・具体物なしで使っていない
- [ ] 色名・書体名だけで終わらず、面積比・サイズ比・余白量・揃え方を書いている
- [ ] 必須の軸を全行埋めている（取れない値は「未確認」）
- [ ] 「やっていないこと」を3つ以上探した
- [ ] 知覚できなかった部分（音・動き・触感など）を推測で断定していない。数値と目視の食い違いを記録した
- [ ] ユーザーが言った「好き／違う」を原文で残し、自分の分析より優先している
- [ ] 文章そのものが「C. 文章・コピー」の典型（対比構文、三点列挙、抽象語）で書かれていない

## B. 制作物の判断

- [ ] 決定表の全行に、引用の根拠と、測った「実物の値」がある。「今回の値」と「実物の値」が違う行が残っていない
- [ ] 参考に無い影・グラデーション・角丸・アイコン・動きを足していない（参考と比べて書く）
- [ ] 参考の極端さを中和していない: 必須の軸のうち、値が参考より「よくある値」の側に寄った軸を数える。寄った軸ごとに根拠を言えなければ修正
- [ ] **既定値との比較**: 必須の軸の半分以上が、決定表の「AI の既定値」と同じなら作り直す
- [ ] **入れ替えテスト**: 固有名詞・ロゴ・商品名を別の案件のものに差し替えても違和感がないなら、その案件専用の判断が足りない
- [ ] 理由のないランダムな崩し・わざとらしい手書き風・ノイズを足していない（崩すのは内容に理由がある1〜2か所だけ）
- [ ] 参考作品の文言・画像・ロゴ・固有のモチーフをコピーしていない
- [ ] 依頼文・資料に無い事実（実績、受賞、人数、お客様の声、評価の星）を作っていない
- [ ] 並べた1枚で見て、表示崩れ・はみ出し・読めない文字が無い（375px も見た）

## C. AI の典型（詳細と置き換えの方向は `references/ai-tells.md`）

**判定の規則**: 当てはまったら、参考作品のどこを根拠にしているかを言えない限り使わない。参考にも同じものがある場合は、それが参考の顔（なくすと参考らしさが消える要素）になっていることを確かめて免除リストに入れ、参考と同じ使い方に限って使う。第2層は参考にも似た要素があるため「根拠がある」と錯覚しやすい。こちらが本命。

### Web・画面
- 第1層: [ ] 紫〜青のグラデーション・Tailwind 既定色・blob・グラスモーフィズム　[ ] 中央揃えヒーロー（大見出し＋サブコピー＋ボタン2つ）と pill 型バッジ　[ ] アイコン＋見出し＋説明の3カード、Features→Testimonials→Pricing→FAQ→CTA の順　[ ] 角丸＋薄い影のカードを全部に、hover で一律に浮く　[ ] Inter / Roboto / system-ui のみ、見出しと本文の差が小さい（または 800 の太字見出し）　[ ] 見出しの頭に絵文字・汎用アイコン　[ ] 全要素が同じ fade-up
- 第2層: [ ] 生成り・アイボリー・グレージュ地＋墨色文字＋くすみ差し色1色　[ ] オールドスタイル欧文＋明朝見出し＋ゴシック本文　[ ] 字間の広い英大文字ラベル＋小さな和文、「01 / About」型の番号ラベル　[ ] 全画面写真＋暗いオーバーレイ＋中央コピー、「Scroll」＋縦線　[ ] 1px 罫線のカード、pill 型の線ボタン、透明→blur の固定ヘッダー　[ ] 中央揃えのセクションが同じ幅・同じ余白で縦に積まれるだけ　[ ] 余白に置いた縦書きの和文見出し・店名・キャッチ（参考にあれば免除リストへ。場所・大きさを参考と同じに限る）

### 文章・コピー
- 第1層: [ ] 「〜ではなく、〜」「〜だけでなく、〜も」の多用　[ ] 何でも3つ並べる　[ ] 抽象語（革新的、シームレス、寄り添う、紡ぐ、彩る、最高の、〜の世界へ）　[ ] 冒頭の問いかけ、末尾のまとめ・「いかがでしたか」　[ ] ダッシュ、コロン付き見出し、太字の多用、絵文字　[ ] 段落も文も同じ長さ・同じリズム
- 第2層: [ ] 余韻狙いの短い体言止めの連続　[ ] 「ただ、〜したかった。」型の控えめな一人称　[ ] 五感の描写を均等に盛る　[ ] 改行の多い詩的な縦長のコピー

### 画像・イラスト・写真・ロゴ
- 第1層: [ ] 主役が中央・左右対称・背景が浅くぼける　[ ] ティール＆オレンジ、光沢・glow・ハレーション　[ ] 隅々まで均一な描き込み、滑らかすぎる素材　[ ] ロゴの幾何学モノグラム・グラデーション・「つながり」の矢印や波
- 第2層: [ ] 余白の大きい静物、くすんだフィルム調、斜めの柔らかい自然光　[ ] 和紙・水彩のテクスチャを全面にうっすら

### 動画・映像
- 第1層: [ ] 全カットが同じ長さ、静止画にゆっくりズームだけ　[ ] 汎用的に盛り上がる BGM と、拍に関係ないカット　[ ] 全セリフのテロップ、全シーンにトランジション　[ ] 冒頭のロゴアニメ、最後の「Thank you」
- 第2層: [ ] 浅い被写界深度のスローモーションの連続　[ ] ピアノ（またはアコースティックギター）の静かな BGM を全編に薄く　[ ] 縦書きの明朝テロップを余白に置く　[ ] 手元・湯気・木漏れ日などの「丁寧な暮らし」インサートの連続　[ ] 暗転＋白文字の一言で終わる

### 音楽・音声
- 第1層: [ ] 4・8小節単位で予測どおりの展開、教科書どおりの構成　[ ] 王道進行の繰り返し、主和音できれいに解決　[ ] 全編同じ密度・同じ音量、ブレイクや無音がない
- 第2層: [ ] ローファイ風のテープの揺れ・ノイズを全編に　[ ] 雨・波・鳥などの環境音を薄く敷く　[ ] ピアノ単音のアウトロで静かに終わる　[ ] 低域を削った「控えめ」なミックスが全編同じ
