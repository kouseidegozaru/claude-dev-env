# 美術作品・イラスト・写真・ロゴ・グラフィック

## 観察のしかた

1. 画像を実際に読み込んで見る。可能なら全体と、部分を拡大したもの（筆致・質感・細部）の両方
2. 時間をかけて見る順番を意識する：**最初に目が行く場所 → 次に行く場所 → 最後に残る場所**を記録する。これが視線誘導の設計
3. 色は可能なら数値で取る（画像編集ツールやスクリプトで代表色を抽出）。目視なら「推定」と書く
4. 作品の背景（作者、時代、用途、技法）が分かれば添える。ただし分析は画面に見えるものを中心にする

## 要素一覧

| 要素 | 観察すること |
|---|---|
| **構図** | 主役の位置、三分割・対角線・シンメトリー・日の丸などの型、余白（ネガティブスペース）の量と形、視線の流れ |
| **形・線** | 直線的か曲線的か、線の太さと強弱、輪郭の有無、形の単純化の度合い |
| **色** | 主調色、配色の型（同系・類似・補色・無彩色＋1色）、彩度と明度の分布、**色の面積比**、色温度 |
| **明暗（バリュー）** | 明暗の段階数、最も明るい所と暗い所の位置、コントラストの強さ。モノクロにしたときに構図が成り立つか |
| **質感・技法** | 筆致、塗りの平坦さ／ムラ、粒子、紙や素材感、写真ならボケ・ノイズ・シャープさ |
| **光** | 光源の方向と数、硬さ、影の色 |
| **主題・物語** | 何を描いているか、何を描いていないか、見る人に想像させる余地 |
| **スケール感** | 被写体と画面の大きさの関係、細部の密度と粗の配分 |
| **ロゴ・文字の場合** | 字形の特徴、字間、太さ、図形部分との比率、小さくしたときの判読性、白黒での成立 |

## 見落としやすい点

- **明暗の設計**：色の印象の多くは、実は明暗の配置で決まっている。白黒にして確認する
- **描き込みの配分**：全体を均一に描き込まず、主役だけ密にして他を粗くしていることが多い
- **余白の形**：何もない部分が、どんな形をしているか
