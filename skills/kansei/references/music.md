# 音楽・音声・効果音

AI は音を直接聴くことができません。**正直にそれを前提にして**、取り出せる情報とユーザーの言葉を組み合わせます。

## 必須の軸

学習で取る値、プロファイルの「0. 再現トークン」、制作の決定表（BGM の選び方・頼み方の指示書もこの表で作る）の行は、すべてこの9行です。各行の値には出どころを付けます: **［測定］**（スクリプト・ffmpeg の値）、**［ユーザー］**（ユーザーの言葉の引用）、**［公開情報］**（曲の資料）、**［未確認］**。

| # | 軸 | 何を書くか | 取り方 |
|---|---|---|---|
| 1 | 長さ | 秒 | `measure-audio.py` |
| 2 | テンポ | BPM、拍のはっきりさ。拍が弱ければ「未確認」 | `measure-audio.py`（推定。倍・半分の取り違えに注意）、公開情報 |
| 3 | 構成 | 各部の長さ（小節数が分かれば小節数）、繰り返しと変化の位置 | 音量の推移・発音の時刻・スペクトログラムの区切り、楽譜 |
| 4 | ブレイク・無音の位置 | どこで音が止まる／減るか、余韻の長さ | `measure-audio.py`（無音区間、終わりの長さ） |
| 5 | 音量の推移 | 統合ラウドネス（LUFS）、ラウドネスレンジ（LRA）、山の位置 | `measure-audio.py`（ebur128・0.5秒ごとの RMS） |
| 6 | 音の密度 | 1秒あたりの発音の数、重なりの多さ | `measure-audio.py`（発音の数）、スペクトログラム |
| 7 | 始まりと終わり | 立ち上がりの長さ、終わり方（フェード・急に止まる・余韻） | `measure-audio.py`（立ち上がり・終わり） |
| 8 | 音域・明るさ | 高い音・低い音のどちらに寄っているか | スペクトログラムを目視（「推定」と書く） |
| 9 | 音色・編成 | 楽器・声・電子音の別 | **測れない**。ユーザーの言葉か公開情報が無ければ「未確認」。推測で楽器名を書かない |

`measure-audio.py` の出力例（読み方）: 「ラウドネスレンジ 3 LU」なら音量の起伏が小さい（10 LU を超えると起伏が大きい）、「1秒あたりの発音 1 前後」なら音数が少ない。値は比べるための材料で、良し悪しはユーザーの言葉で決める。

### ツールが無いとき

ffmpeg が無ければ数値は出せません。軸 1〜8 は「未確認」とし、ユーザーに次のような選択式で1問だけ聞きます（例:「速さは ア ゆっくり イ ふつう ウ 速い ／ 音の数は ア 少ない イ 多い」）。答えは［ユーザー］として書きます。

## 情報の集め方

1. **ユーザーに聞く**（最も重要）：どこが好きか、聴いてどう感じるか、似ていると思う他の曲。時刻つき（「1:20 のところ」）だと分析しやすい
2. **楽曲の公開情報**：曲名・アーティストが分かれば、テンポ（BPM）、キー、ジャンル、編成、制作背景をWebで調べられる
3. **楽譜・コード譜・歌詞・MIDI** があれば、構成・和声・旋律を直接分析できる
4. **ファイルの解析**（ffmpeg がある場合）：まず `python3 <scripts>/measure-audio.py <file> --spectrum kansei/img/<名前>-spec.png` で必須の軸の大半が取れる。個別に取るなら：
   - 長さ・形式：`ffprobe <file>`
   - ラウドネス：`ffmpeg -i <file> -af ebur128=framelog=quiet -f null -`（統合 I と LRA）
   - 音量の推移（どこが盛り上がるか）：`ffmpeg -i <file> -af "astats=metadata=1:reset=44100,ametadata=print:key=lavfi.astats.Overall.RMS_level" -f null -`
   - 無音区間：`ffmpeg -i <file> -af silencedetect=n=-40dB:d=0.5 -f null -`
   - 波形やスペクトログラムを画像にして見る：`ffmpeg -i <file> -lavfi showspectrumpic=s=1280x480 spec.png`
5. 推測した内容（音色の質感、ミックスの印象など）は「推定」と明記し、ユーザーに確認する。楽器名・ジャンルを推測で断定しない

## BGM を選ぶ・頼むときの書き方（制作）

音を作れない場合の「制作物」は、BGM を選ぶ・頼むための指示書です。決定表の行（必須の軸）ごとに「この範囲なら合う／外れる」を値で書き、出どころ（［測定］［ユーザー］）を残します。例:「テンポ: 90〜110 BPM［測定 98、推定］」「音量の起伏: 小さい（LRA 4 LU 以下）［測定 3.1］」「終わり: 3 秒前後で消える［測定］」「音色: 未確認（ユーザーの言葉『〜』に合うものを、候補を聴いて選ぶ）」。候補曲が手に入ったら、同じ `measure-audio.py` で測って表と照らす（実物照合）

## 要素一覧

| 要素 | 観察すること |
|---|---|
| **構成** | イントロ・Aメロ・サビなどの並びと長さ、サビまでの時間、繰り返しと変化 |
| **テンポ・リズム** | BPM、拍子、ノリ（ハネる／まっすぐ）、リズムの密度、休符 |
| **旋律** | 音域、跳躍の多さ、繰り返されるフレーズ（モチーフ）、山場の位置 |
| **和声** | キー（長調・短調）、よく使うコード進行、緊張と解決の位置 |
| **音色・編成** | 楽器の構成、生音か電子音か、声の質（息っぽさ・張り） |
| **ダイナミクス** | 音量の起伏、盛り上がりの作り方（楽器を足す／音域を上げる／止める） |
| **空間・ミックス** | 広がり、残響の量、低音の量、音の密度 |
| **歌詞・言葉** | 視点、語彙、具体と抽象の配分、音（母音）の響き |
| **間** | ブレイク、無音、余韻 |

## 見落としやすい点

- **引き算**：盛り上がりの直前に楽器を減らす、など「減らすことで効かせる」設計
- **緊張と解決**：期待させてから満たす（あるいは裏切る）タイミング
- 効果音・ジングルなら：長さ（ms）、立ち上がりの速さ、音程の上下が与える印象（上がる＝肯定、下がる＝否定など）
