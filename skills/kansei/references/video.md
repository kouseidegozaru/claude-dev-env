# 動画・映像・アニメーション

AI は動画をそのまま「見る」ことができないため、**静止画と数値に変換して**観察します。

## 必須の軸

学習で取る値、プロファイルの「0. 再現トークン」、制作の決定表の行は、すべてこの10行です。量の軸（1〜6）と構造の軸（7〜10）の両方を埋めます。取れない値は「未確認」。

| # | 軸 | 何を書くか | 取り方 |
|---|---|---|---|
| 1 | 尺 | 全体の長さ | `ffprobe` |
| 2 | 平均カット長と最長／最短 | カットの長さの平均とばらつき | カット点の検出 |
| 3 | トランジション数 | カット以外のつなぎ（ディゾルブ・ワイプ等）の数 | 代表フレームの一覧と、切り替わり前後のフレームを目視 |
| 4 | テロップの量 | 文字が出ている時間の割合、1枚あたりの字数、位置 | 一定間隔のフレーム一覧を目視 |
| 5 | 色（彩度・色温度・明暗） | 主調色と面積比、黒の締まり | 代表フレームに `count-colors.py` |
| 6 | 音量の推移 | ラウドネスと起伏、BGM・声・効果音の有無 | `scripts/measure-audio.py`（動画ファイルをそのまま渡せる） |
| 7 | 構成 | 起承転結の配分（何秒で何を見せるか）、冒頭の掴み、終わり方 | カット一覧と目視 |
| 8 | 無音・静止の「間」 | 何も起こらない時間の長さと位置 | 無音区間の検出＋フレーム差の小さい区間 |
| 9 | 構図とカメラの動き | 被写体の位置、寄り／引きの比、固定・パン・手持ち | 代表フレーム、連続フレーム（動きは「推定」） |
| 10 | 音と画の同期 | カット点が拍・音のアクセントと合っているか | カット点の時刻と `measure-audio.py` の発音時刻を並べる |

## 観察のしかた

1. **ffmpeg / ffprobe があるか確認**（`ffmpeg -version`）。あれば以下ができる。なければ、代表的な場面のスクリーンショットとカットの説明をユーザーにもらい、測れない軸は「未確認」と書く（インストールを前提にしない）
2. **基本情報**：`ffprobe -v error -show_format -show_streams <file>` で長さ・解像度・フレームレート・アスペクト比
3. **カット点の検出**：シーンが切り替わった時刻を取り、カットの長さ（テンポ）を出す
   ```
   ffmpeg -i <file> -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time
   ```
   PowerShell では `grep pts_time` の代わりに `Select-String pts_time` を使う。しきい値 0.3 は目安。カットが拾えすぎ／拾えなさすぎなら 0.2〜0.5 で調整する
4. **代表フレームの切り出し**：カットごとに1枚、または一定間隔で並べた一覧画像を作って見る
   ```
   ffmpeg -i <file> -vf "fps=1/2,scale=320:-1,tile=6x5" -frames:v 1 contact.png
   ```
5. **音**：音楽・効果音・ナレーションがある場合は `references/music.md` も使う。`python3 <scripts>/measure-audio.py <動画ファイル>` で音量の推移・無音・発音の時刻が取れる。ffmpeg 単体なら `ffmpeg -i <file> -af ebur128=framelog=quiet -f null -`（統合ラウドネスとラウドネスレンジ）
6. 動き（カメラワーク、モーションの質感、イージング）は静止画からは分かりにくい。連続した数フレームを切り出して比べるか、ユーザーに説明してもらい、推測の部分は「推定」と書く

## 要素一覧

| 要素 | 観察すること |
|---|---|
| **構成・尺** | 全体の長さ、起承転結の配分（何秒で何を見せるか）、冒頭何秒で掴むか、終わり方 |
| **テンポ・カット** | 平均カット長と、そのばらつき。どこで速く・遅くなるか。音楽の拍とカットが合っているか |
| **画（構図）** | 被写体の位置（三分割・中央・余白）、寄り／引きの比率、アングル、被写界深度 |
| **色（グレーディング）** | 色温度、彩度、コントラスト、黒の締まり、肌の色の扱い、シーン間で色が統一されているか |
| **光** | 順光／逆光／サイド光、硬い光／柔らかい光、明暗の比 |
| **動き** | カメラの動き（固定・パン・ドリー・手持ち）、被写体の動き、モーショングラフィックスの速さとイージング |
| **トランジション** | カットのみか、ディゾルブ・ワイプ等を使うか、その頻度 |
| **文字（テロップ）** | 書体、サイズ、位置、出る時間、出入りの動き、量 |
| **音** | BGM の雰囲気、効果音の量、ナレーションの声質と話速、無音の使い方 |
| **間（ま）** | 何も起こらない時間の長さと位置。余韻を残す箇所 |

## 見落としやすい点

- **カットの長さのばらつき**：一定の速さより、速い連続のあとの長いカットが印象を作る
- **音と画の同期**：拍・アクセントに合わせたカットや動きは「気持ちよさ」の大きな原因
- **やっていないこと**：テロップを出さない、BGMを止める、トランジションを使わない、など
