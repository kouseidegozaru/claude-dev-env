# 文章・コピー・その他の分野

## 文章・コピー・ネーミング

### 必須の軸

学習で取る値、プロファイルの「0. 再現トークン」、制作の決定表の行は、すべてこの10行です。量の軸（1〜5）と構造の軸（6〜10）の両方を埋めます。数えられる軸は `python3 <scripts>/measure-text.py <ファイル>` で参考と制作物を**同じ数え方**で数えます（`## ` 見出しごとに測る）。

| # | 軸 | 何を書くか |
|---|---|---|
| 1 | 文の長さ | 平均・最長・最短（字）。ばらつきの大きさ |
| 2 | 漢字率 | 漢字・カタカナ・ひらがなの割合 |
| 3 | 具体物の数 | 数字の数、固有名詞の数（固有名詞は手で数える） |
| 4 | 対比構文・三点列挙の回数 | 「〜ではなく」「〜だけでなく」、3つ並べる列挙 |
| 5 | 抽象語・宣伝語・記号 | 宣伝語の数、！・？・ダッシュ・絵文字・太字の数 |
| 6 | 語尾 | です・ます／常体／体言止め／言いさしの分布 |
| 7 | 結論の位置 | 冒頭で言い切るか、最後に置くか、言わないか |
| 8 | 段落の組み方 | 段落の数、1段落の文の数、1文だけの段落の有無 |
| 9 | 視点と距離 | 一人称・二人称の有無、読み手への呼びかけ方 |
| 10 | 締めに置くもの | 最後の文の役目（実務の知らせ、余韻、呼びかけ等） |

機械で数えられない軸（7・9・10 と固有名詞）は、`measure-text.py` が出す最初の文・最後の文を見て自分で判断し、例として参考の文の**構造**（例:「最後の1文は問い合わせ先だけで、感想を足さない」）で書きます。参考の文そのものを再現ルールに書き写さない（制作時のなぞりを防ぐ）。

### 要素一覧

| 要素 | 観察すること |
|---|---|
| **長さとリズム** | 1文の文字数とそのばらつき、段落の長さ、体言止め・倒置の頻度、読点の打ち方 |
| **語彙** | 漢字・ひらがな・カタカナの比率、専門用語の量、擬音語、外来語 |
| **視点と距離** | 一人称・二人称、語尾（です・ます／だ・である／話し言葉）、読み手との距離感 |
| **具体と抽象** | 数字・固有名詞・五感の描写の量、抽象的な言葉との配分 |
| **構成** | 結論の位置、問いかけ、反復、対比、意外性の置き場所 |
| **余白** | 言わずに想像させている部分、省略 |
| **音** | 声に出したときの響き、語呂、母音・子音の印象（ネーミングでは特に重要） |

観察のしかた：文字数・文の長さは実際に数える（`measure-text.py`）。数値で書くと、制作時に「短くした」が具体的になる。制作物も同じスクリプトで数えて、決定表の「実物の値」を埋める。Web 用の手順（スクリーンショット・色の面積比など）は文章には使わない。

## その他（料理、空間、プロダクト、ファッション、UI の手触りなど）

AI が直接知覚できない分野では、**写真・図面・仕様・ユーザーの言葉**を材料にします。どの分野でも、次の8つを**必須の軸**として使います（学習の値・再現トークン・決定表の行）。写真があれば色の面積比は `count-colors.py` で取れます。知覚できない軸（味・香り・手触りなど）は、ユーザーの言葉か資料の引用で書き、無ければ「未確認」。

| 観点 | 例 |
|---|---|
| **素材・質感** | 素材の種類、表面の仕上げ、温度感、重さ |
| **形・比率** | 全体の比率、角の処理、厚み、部分と全体の関係 |
| **色・光** | 主調色、面積比、光の当て方 |
| **構成・配置** | 何をどこに置くか、余白、動線 |
| **時間・順序** | 体験する順番、最初と最後の印象、変化 |
| **五感** | 視・聴・触・味・嗅のうち何が主役で、何を抑えているか |
| **機能と感性の関係** | 使いやすさのための形が、美しさにもなっているか |
| **文脈** | 誰が、いつ、どこで、どんな気持ちで触れるか |

分野固有の観点が必要な場合は、その分野の基本的な評価軸を調べてから分解してください（例：料理なら味の五味・食感・温度・盛り付け・器、空間なら天井高・採光・素材・動線）。
